# 玄学能力与体系压力测试 v0.2.0

2026-10-23 · 形成可辨认、有完整推导的人物能力画像，再将画像放入具体实践任务。先执行下面的论断框架，最后写成散文；不把检查表当报告。

## 本版负责什么

本 skill 是统计塔罗的专题报告入口。已有抽样、统计计算、牌义资料和四元素本体继续使用；玄学能力题的论断顺序与成稿由本入口负责，不再并行执行原统计 SOP 的解读阶段或复用旧报告结论。一般统计塔罗问题仍走原 skill。

将原统计 skill 的目录记作 `BASE_SKILL`，本目录记作 `REPORT_SKILL`。按实际安装解析，不根据客户端名改写路径：

1. 优先采用用户明确给出的原统计 skill 路径；没有显式路径时，检查本 skill 的兄弟目录 `statistical-tarot-elemental-reading/`。
2. 若仍位于仓库的 `addons/mystic-talent-report/` 内，检查上两级目录。任何候选都须确认 `SKILL.md` 的 `name` 是 `statistical-tarot-elemental-reading`，且有 `data/tarot/` 与 `references/`，再记作 `BASE_SKILL`。
3. 找不到有效依赖时，说明需要安装 [原统计 skill](https://github.com/Kico-Tachagemofet/statistical-tarot-elemental-reading) 或提供路径，不静默换方法。

将牌库目录记作 `CARD_DATA = BASE_SKILL/data/tarot/`。Markdown 链接相对当前文档；`BASE_SKILL/...`、`CARD_DATA/...` 与 `REPORT_SKILL/...` 是上述解析后的路径。领域资料随本包位于 `references/domains/`，不依赖私有案例或实验目录。

本次启动锁定问题、已有材料路径、牌义包开关、输出目录、是否使用用户经验。优先读取已有 `protocol.json`、`statistics.json`、五堆数据卡；缺件先恢复读取或说明限制。只有导出摘要时，可完成限定于已提供牌的解读，不把它冒充完整 78 张数据。只有用户明确要求新测且尚无抽样时，才由原统计 skill 完成一次抽取；一旦随机组件已开始，不重抽替换部分或不确定结果，回到已有回执处理。抽样完成后转回本流程。

## 每次必读与条件读取

每次先读以下三页，它们共同构成本版的完整论断框架：

1. [论断与关系](references/inference-contract.md)：统计、功能、因果和画像的连接方式。
2. [元素应用口径](references/element-application.md)：如何使用原七张方法卡，以及本专题如何处理原方法的应用直断。
3. [体验、转译与制作](references/experience-processing.md)：接收类问题和实际产出的区分。

问题涉及玄学能力、灵视、灵感或内在经验时，另必读 [四组题型框架](references/seership-frameworks.md)。它在步骤 0 确定取象对象，在步骤 2–3 分别检查火水、水自身、水土、风及火风的具体作用，先于画像冻结。它属于本题的取象方法，不是最后才加载的传统门槛。

牌义与占星读取 [card-astrology.md](references/card-astrology.md)。小牌、宫廷和基础大牌读取 `CARD_DATA/{pips,courts,atu}.json` 或本次数据卡中实际出现的完整条目；条目只有摘要时明确资料精度。需要增补摘要未含的牌义内容时查原典，不宣称已读全文；已有牌义结合题型框架形成的功能推演，标明推导即可，不要求原典直接写出“灵视”才允许判断。

作者包开启时，按 `BASE_SKILL/references/meaning-pack.md` 解析已启用的包，读取其 `manifest.json` 及本次有关大牌的完整正文，记录单牌版本和每张牌的 `meaning_use`（正文短引＋用于哪项判断）；Book T 对应属性保留来源，作者解释不冒充原典。作者包关闭时，采用本次指定的 Book T 语义，不暗中补用作者正文。明确开启却缺包或缺正文时，停止相应资料步骤，不能静默退回关闭。开关、牌义来源和版本整次运行固定。

合成区分测试若明确给了匿名符号的完整内联语义，直接用该语义和主元素标签，不去真实牌库寻找它，也不把它当成真实 DLC 安装。合成测试的给定相对强调状态只用于测试方法，不补造次数或 p 值。

具体传统、支线和服务角色的知识到步骤 5 才加载；“本题在研究怎样的内在活动”由步骤 0 前置，不与传统门槛混为一层。只读取本轮授权的资料；不自动加载私人背景或旧案例。牌义来源、开关和版本记入 AUDIT，便于复核与比较。

## 不随输出阶段变化的三条关系规则

**偏多的牌没有自带的时间顺序。** 次数、z 排名、牌号、同一花色的序列、正逆比例和大牌路径都不是事件时间。

**同种元素只并列辨认形态，不允许推成“先 xx、后 xx”的时间关系或因果关系。只有不同元素之间才有资格提出因果候选。** 跨元素也必须解释具体作用并给出两端依据；不同元素本身不够。因果方向与实际先后分别说明依据。

同元素按主元素识别，不按牌堆位置偷换：大牌按记录的元素标签并入，宫廷按花色保留主元素、外层说明方式；未指定的大牌不为凑关系强行赋元素。用户明确讲述的先后可以作为用户经验单列，不能伪称是同元素牌推出来的；它也不构成改写本条的例外。

## 步骤 0：锁定任务与事实

在 AUDIT 的开头简记四项：

- 这次在问谁的哪项能力、在什么任务中使用；语境未给定的对象不补。
- 当前任务怎样算完成。理解一次经验、讲给别人听、完成一件作品、持续运用、对外服务可以是不同目标。写作任务中的文本可以就是成品。
- 材料来自原始统计、导出复核、用户经验还是合成测试；原抽取回执是否可核；哪些频数、正逆和基线项未知。
- 本次牌义源与开关、报告 skill 版本、用户经验是否隔离。旧报告的 A1/A2、结论和建议不当作牌证复用。

已给清楚的任务直接沿用。多个任务并存时保留各自完成标准，不把一个任务的未完成转给另一个任务。灵视／灵感题先确定符号正在描述输入作用、内部体验、材料加工还是连接领会；这类抽象作用对象可由原问和牌义共同确定，不需要先取得用户经历。没有指定视觉、梦境等模态，不代表上述功能一律未覆盖。

### 保留原统计口径

沿用已给出的次数、z、分段和校正信息，不改变抽样与检验方法。1000 次时，小牌每张预期约 14.29、大牌每张约 9.09；单牌按 `|z|<1` 为基线、`1≤|z|<2` 为普通偏离、`|z|≥2` 为极端候选。Holm 校正只作记录，不删牌；摘要未提供的 p、正逆和未列牌状态不补造。

五堆总量使用原有相对读口径，不套单牌分段：N 次时每堆预期 `N/5`，标准差 `sqrt(N×0.2×0.8)`；1000 次约为 12.65。最高与最低相差超过一个标准差时，最高可标相对偏多、最低可标相对偏少；否则五堆持平。并列最高／最低同样保留，中间堆不因此强造高低分档。总量判断与内部单牌集中分开，后者不能改写为全元素过量。

**正逆比例只作方向探针，不换算成能力、成功率、失效率或好坏比例。** 逆位可提示同一动作的受压、内折、位置交换或表达变化，但方向须由具体材料收束，不能凭多数逆位自动选负面分支。正逆、旬星星座尊贵与 Book T 的 well/ill-dignified 是不同层；本盘没有左右邻位，不伪造邻位尊贵，条件分支按完整牌义及全场支持／牵制判断。未知正逆保持未知。参考页所称“沿原 skill 作探针”，在本专题由本段承接，不再回调旧 SOP。

## 步骤 1：完整牌义与无序形态谱

分读五堆，可顺序完成；有并行能力时可按堆拆读，但各分读者必须收到本入口三条关系规则和当前牌义版本。工具不足不跳过分读。

对每张突出牌辨认：核心动作、作用对象候选、条件分支、限制；再用源质、占星和宫廷复合细化动作。高低偏离和基线分别记在这些内容旁边。普通偏离用来细化形态，不能仅凭普通偏离生成独立的大范围人物断语；极端候选也是待解释的显著位置，不是已经证实的性格。

每个主元素形成一段**无序形态谱**：哪些形态被强调、哪些较少强调、明确已知在基线的是什么；区别、并存和张力是什么。不写“首先—接着—最终”，不把同元素牌画成箭头。

牌义自身包含的阶段词可以保留为该种形态的内容，例如“成功后未跟进”；不能据此把另一张同元素牌认作这次成功、前因或后果，也不能默认本人生平确实发生了该过程。

## 步骤 2：性质 → 本题功能 → 元素状态

结合原七卡和本专题元素口径，逐条完成有实质内容的翻译：

> **具体内容／动作 → 以怎样的性质运行 → 本题中正在处理什么、产生什么 → 支持条件与限制。**

先保留动作，再说热冷干湿、方向、空间、轻重和层次；不从“水多”先填“接收强”，不从“土少”先填“持续实践弱”。同一功能可有不同做法，同一元素可承担不同功能。

每个元素给出状态判断：总量是背景，具体形态定质，全场条件决定它是丰富、有力、受限、紧绷、过载或其他什么状态。没有问题证据时可以只有长处；不知道阻碍在哪时说明该点未定，不配造积压与失败。

接收、理解、语言表达、实际制作或长期工作参与主线时，按 experience-processing 页辨清相关节点；无关节点不强填。灵视／灵感题按 seership-frameworks 页先检查水的内容与内在形态，并提出其他三组作用候选，不能只把水保留在对现实结果的感受上。

## 步骤 3：跨元素关系与有效推断

按 inference-contract 页逐项检查跨元素的共创、两极、因果或背景关系。只写当前两端有具体内容的关系。每条有效关系都要说出它改变了什么；无法建立关系时，保留各自形态和未定连接，这也算完成。灵视题的 K1–K4 分别留下“功能支持到哪层／具体牌义与作用／尚未确定的细项”，不因模态、来源或稳定度未知而撤销已有支持的功能候选，也不强迫四项全部成立。

共享节点不自动串链。有多个成立的两两关系时，分别保留；要说是同一对象的一段流程，需要另外提供对象连续和时间依据，不能从相同“水”字补出。原始统计不提供这个时间依据。

同元素牌可以互相限制一个解释覆盖得多宽，不能互为此人的前因后果。没有有效跨元素因果，就不输出牌面原因诊断；已有的状态和能力判断仍可成立。

## 步骤 4：合议并固定能力画像

先比较当前功能的所有实现方式，再决定强项、条件和断点。某种方式较少被强调，只能限制“该方式主导”的解释，不能消灭另一张牌支持的同类功能。

使用三种支持状态：**支持／相反材料／未覆盖**；另记统计强调程度。它们是两条轴，“未覆盖”不写成弱，“偏少”不写成不存在。即使为极端负偏差，也先排除“由该种形态主导”，不据此否定人的整项能力。支持状态带具体层级：功能可用、是否长处、感官模态、稳定度与来源分别判断；“模态未覆盖”不能缩写成“接收未覆盖”。

合议有张力的判断，例如某任务能反复做实，另一项却被判难以持续：须指出它们的任务、内容或操作方式差别，否则回退范围过大的判断。不能将一个正面功能保存于 A3，却任由 A4 泛化否定它。

形成约 3–5 条有辨识度的能力主线 A1…，按实际材料可增减。七模块用于检查覆盖：直觉整合、灵感生成、辨识收束、象征理解、转译表达、定向施行、持修调节。商业另分定位、表达、包装、交付、组织、经营，不按对称模板补长短板。

接收矩阵只登记有材料的细项：梦境、视觉、听觉、身体、非言语领会、外部符号材料、主动观想、对象互动；再分自发／诱导条件、保留、辨识、转译、边界与退出。矩阵用于细化已辨明功能，不要求先确定频道才允许论输入或领会。用户经验单列来源，不倒写成牌证。商业轴与实践能力各自判断，不从包装推真假，也不从实践强推会经营。

每条 A 记录 **判断＋处理对象／适用任务＋关键牌义与功能依据＋支持状态及反证＋尚未覆盖的邻接功能**。若涉及因果或时间，加关系编号和单独时间来源。这个记录连同判断一起冻结为 `profile_frozen`；只有用户新校准或发现证据错误才出新版本，保留改了哪一步。

## 步骤 5：具体领域压力测试

已有选择就沿用；用户希望勾选时，在画像完成后提供十四体系列表，请选 3–5 项。不要求互动或尚未选择时，按画像最有依据的 3–5 项继续，记录默认选择理由，不把同一句话套进全部体系。现在读取 [domain-pressure.md](references/domain-pressure.md) 的领域索引和所选 `references/domains/` 完整主卡，再读 [field-affinity.md](references/field-affinity.md)。

领域任务链表示实践的要求，不是这个人的已发生过程。按具体支线取需要的节点，可合并、循环或省略无关项；某项任务需要接收、记录或维护，并不证明这个人已经做了或做不到。

对每个领域写：**画像里的哪项功能 → 这项具体工作怎么用它 → 哪个衔接有支持、哪个有相反材料、哪个未覆盖 → 这会改变什么。** 有明确缺口再写通过条件。门槛的实际条件未核清时保留未定，不能用低强调或未知触发“不适合／不能走通道”的排除。

灵视与通灵分支先用 experience-processing 页确定形式、理解与加工目标，再读取领域卡；旧卡里的固定人群模板和缺项断言不套用。宫位和喜乐仅细化任务场景，不虚构本命位置、月水相位或天赋 gate。

## 步骤 6：成稿与末次核对

写正文前读取 [报告写法](references/report-writing.md)。交付 `REPORT.md` 与 `AUDIT.md`，写入本轮指定的新输出目录；只在用户要求修订时改既有稿，保留原抽样。正式归档或对外发布遵循所在项目的授权规则，生成工作稿不自动授权发布。

REPORT：一句有力度的定调，默认 4–6 个随内容生成的小标题；先写有辨识度的能力怎样运作，再写领域任务后果。具体、直接；不用把整篇降成“可能、待验证”，也不把没有依据的具体习惯写得斩钉截铁。每节末一行简短依据指向 A 与必要关系。关系类型、统计和逐项来源留 AUDIT。

**灵视措辞单列：所有面向个人的灵视论断均用“你可能……”或“你或许……”开句。** 包括接收、体验、连接领会、转译、加工，以及强项、限制和适配倾向；不在同段第二句改成“你有／你能／你就是”的裸断，也不用“可能”包装仍然越界的内容。统计事实、牌义原文、方法定义和 AUDIT 的支持状态照实写，不机械加人称。标题也不另行下确定的个人判断，可写“体验怎样形成材料”等主题。

AUDIT：输入与版本 → 无序形态谱及关键牌义 → 性质／功能判断 → 有效跨元素关系与未定连接 → 冻结画像及接收／制作细项 → 领域应用 → 有意义的竞争解释与开放项。每个关键主张能沿这条线回查；无需逐句暴露所有思考。

末次检查四点，失败修相应段，不重抽：

1. 有没有从牌号、次数或同元素并存写出先后／因果？有没有借宫廷外层、行星、文字换标签或“两端强、中段薄”的发展隐喻绕过同元素规则？
2. 成稿是否仍是同一个处理对象和任务？体验的满足有没有变成工程已完成，概念重组有没有变成非语言体验自动可读？
3. 未覆盖／低强调有没有变成能力缺失？细磨、反复、反馈、持续和交付有没有被合成一个指标？
4. 支持充分的功能与关系是否得到明确判断，还是整份都退成未定？重点体系能否看出不同的实际接法？灵视的功能、模态和稳定度有无分层，所有给人的灵视判断是否使用“你可能／你或许”？
