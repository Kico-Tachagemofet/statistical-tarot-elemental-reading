# Vodou（海地伏都）

> 本卡按「实践支线」写，不把某一个家系、职分或角色的条件当成整个 Vodou 的统一门槛。

## 体系定位与传承

**路径类型**：封闭-授权（按家系／社群／职分；不是统一门槛）。

海地 Vodou 是活宗教，不是单一教会或统一组织。它包含：

- **个人／家庭敬奉**：家族传承的 lwa-rasin、家中的小祭坛（wogatwa）、日常供奉与节期。
- **集体祭仪**：歌、鼓、舞蹈、供奉、宴飨、附体、社区互助。
- **现实求助**：个人、家庭、群体在疾病、工作、经济损失、家庭危机等情境中求助。
- **宗教职分**：houngan／mambo 等祭司与仪式主持；需要知识、训练、传授与相应资格，具体形成方式依传统。

不同家系、house、社群与传统的规矩不同：Asògwe 等传统有入门层级；Makout 类型的实践者、以及一般 sèvitè lwa，并不必然经过固定入门程序。**正式入门在部分传统与职分中是必要的，但不是所有实践的统一前提。**

## 它是什么

通过与 lwa、祖先和共同体的关系，回应对个人、家庭与群体的保护、疗愈、秩序与现实需要。实践可以落在个人／家庭敬奉、集体祭仪、歌舞鼓乐、附体媒介、占问服务或祭司职分等不同位置。

## 它不是什么

不是「巫毒娃娃」；不是 Hoodoo；不是「所有人都在附体」；不是「必须先加入一个正式组织才能做任何事」；也不是「没有传承的自由 solo」。

## 意志放在哪一层

- **个人／家庭敬奉**：关系与日常持守。
- **集体祭仪**：共同体、仪式协同、服务。
- **附体媒介**：关系中的媒介角色；不是个人秀。
- **占问／服务**：实用技法＋关系；回应具体需要。
- **祭司／传授**：职分、责任、传授；宗教效果＋共同体。

它不是一条「道路本身」；是活宗教里的不同位置。

## 操作形式（按支线）

| 支线 | 实际在做什么 | 主要要求 |
|---|---|---|
| **个人／家庭敬奉** | 家中祭坛、供奉、节期、承诺、日常照料 | 礼俗、持守、关系、细节 |
| **集体祭仪与协同** | 仪式次序、供奉、宴飨、社区分工、现场回应 | 看懂当下需要、配合、维持秩序 |
| **歌舞、声音与鼓乐** | 领唱、合唱、主鼓手、其他乐手、舞者 | 声音、节奏、身体协调、仪式知识（按角色） |
| **附体媒介** | 在相应传统中承担媒介角色 | 实际状态与适性；不是全员要求 |
| **占问／辨事与实际服务** | 理解问题、联系传统知识、选法、咨询、疗愈、实际帮助 | 辨事、选法、把知识落到具体处境 |
| **祭司与传授** | 主持、传授、承担社区责任 | 广泛知识、判断、责任、相应资格 |

## 基本功与门槛

- **核心能力**：关系与礼俗、仪式知识、社区协同（按支线）、边界感。
- **硬门槛**：**没有一条覆盖全部 Vodou 的统一硬门槛。** 祭司、某些仪式角色与外来者参与，需要相应的家系／house／社群关系与允许；这是**参与条件**，不是能力短板。**附体媒介**只在这一支看个人适性，不是整个宗教的准入条件。
- **门槛按支线（定性）**：个人／家庭敬奉——有家系／社群传承者低，外来者中；材料／仪式操作——中；独立辨事／选法——中高；附体媒介——个人适性；复杂祭司工作——高。
- **必要能力（按支线）**：个人／家庭敬奉＝礼俗与持守；集体祭仪＝次序与协同；歌舞＝声音／节奏／身体（按角色）；占问＝辨事与选法；祭司＝知识、判断、责任。
- **加分能力**：语言（海地克里奥尔语）、历史与文化知识、音乐、疗愈、组织、教学。
- **适配条件**：愿意学礼俗与语言；能接受社群边界与长期关系；外来者要能先建立关系，而不是自由取用。
- **可补偿短板**：语言、歌曲、仪式细节、材料知识可以学；经验和判断靠长期参与。
- **不可补偿短板（只限这一支的能力条件）**：如果一个人在附体媒介这一支里长期很难进入相应状态，以媒介为主要目标可能投入与收获不成比例；这不代表整个 Vodou 不匹配。**没有授权／没有社群关系不属于能力短板**，放在「授权与边界」。

## 个人长处（匹配的重点）

| 长处 | 在本卡中的具体表现 |
|---|---|
| **持守与照料** | 能把供奉、节期、承诺与日常细节落实下来，让关系有连续性。 |
| **具象取象与材料操作** | 看得出一件东西（材料、形状、颜色、动作）在这个场合能承担什么作用，并能落实成做法。 |
| **现场协同与秩序** | 能看懂仪式当下需要什么，配合分工，让多人参与的过程有秩序。 |
| **声音／节奏／身体** | 能通过声音、节奏与身体进入仪式，并与现场配合；按领唱、鼓手、合唱、舞者等角色发挥。 |
| **辨事与选法** | 能把传统知识与眼前的具体处境连起来，判断哪些做法合用。 |
| **附体媒介的适性** | 在相应传统中能进入媒介角色；单独看这一支，不代表整个宗教。 |
| **主持与传授** | 能组织复杂事务、承担关系责任、维持仪式与传授；资格另按传统。 |

> 这些是不同的长处；一个人可以很会材料与辨事，却不容易附体；也可以在现场协同很强，但独立辨事还在学。报告要写「哪一支」，不写「适不适合 Vodou」。

## 内部支线（谁容易上手，谁吃紧）

- **个人／家庭敬奉**：有家庭／家系传承的人容易上手；没有关系来源的外来者，先学礼俗与建立关系。
- **集体祭仪与协同**：适合能读现场、愿意配合的人；不需要本人附体。
- **歌舞／声音**：适合音乐、歌唱、身体表达型；不会打鼓／跳舞的人仍可做供奉、照料、协助。
- **附体媒介**：适合在这一支有实际状态与适性的人；其他人可以参与支持角色，不被判为「不适合整个宗教」。
- **占问／辨事**：适合能把知识落到具体处境的人；「联想丰富」不等于「选得恰当」。
- **祭司／传授**：适合愿意长期学习、承担责任并获得相应资格的人；门槛高，且依传统。

## 它给什么

关系、保护、疗愈、现实帮助、共同体、意义、职分；代价是长期学习、承诺、社区责任与边界。

## 授权与边界

- 没有统一的「社区授权」门槛；授权按家系／house／角色。
- 祭司、某些仪式角色、外来者参与，需要相应关系与允许；不要自学冒充 houngan／mambo，不要自封 asson。
- **「没有授权」是参与条件，不是能力短板**；不要用「天赋」绕过授权，也不要把授权写成天赋报告里的缺陷。
- 不把 lwa 当工具；不挪用封闭仪式；尊重非裔离散社群的产权与边界。
- 部分传统涉及动物献祭；按具体传统、社区规范与当地法律，不在本卡展开。

## 安全性

- **按实际动作区分**：个人／家庭敬奉、材料操作、集体祭仪、附体媒介与复杂祭司工作，按具体角色、训练和支持条件分别处理。
- **主要风险**：附体的低可控／低可逆；群体权力、财务依赖、情绪卷入；文化挪用；把结果当医疗／法律／金融保证；动物献祭的伦理与法律。
- **安全条件**：社群问责、grounding、停止条件、健康边界、可退出；附体不在无人看护下自学。
- **不适合**：想绕过社区关系自由练习的人；把附体当表演或猎奇的人；正在心理危机中的人；不愿承担长期关系的人。

## 学习入口（可选）

**不做仪式试探。** 先读可靠的历史／民族志与社群公开介绍，学习礼俗、语言与边界；如果真有召唤，找正规 house／祭司建立关系，而不是买「Vodou kit」或按短视频自学附体。已有家庭／家系传承的人，按自己的传统学习。

## 常见误读 / 相邻区别

Vodou ≠ Hoodoo（Hoodoo 另见 [Hoodoo／Conjure／Rootwork](hoodoo-conjure.md)）；Vodou ≠ 巫毒娃娃／恐怖片；Vodou ≠ 所有人都在附体；Vodou ≠ 必须先加入正式组织才能做任何事；Vodou ≠ 没有传承的自由 solo；Vodou ≠ 一个 house 的规矩适用于全部。

## 画像压力测试

先确定家庭敬奉、现场协同、歌舞、材料、辨事、媒介或祭司角色，再调用相关画像。照料可以维持承诺，现场判断可以接住多人分工，声音与身体能力可以进入仪式表达；附体适性单独看。将优势放进该角色的实际次序，指出接续与条件；家系、社群关系和职分资格另列，不把缺少授权写成能力缺陷。

正文写此人的长处怎样完成任务；断点与补充条件只在材料支持时写入。牌证、竞争解释与未覆盖项放入 `AUDIT.md`。
