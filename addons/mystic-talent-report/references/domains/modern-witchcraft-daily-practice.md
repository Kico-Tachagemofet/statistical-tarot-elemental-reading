# 现代巫术与日常施术（威卡／个人施术／容器与材料）

> 这张卡收的是当代常见的实践语境与组合方式；蜡烛、草药、容器等媒介有更早、更多样的来历，不都属于威卡。
> 德鲁伊、凯尔特、北欧、希腊等敬奉与传统复兴实践见 [现代异教与传统复兴实践](nature-religion.md)。本卡集中于日常施术，混沌魔法作为独立施术取向纳入。

## 体系定位与传承

**路径类型**：已建立＋半建立＋自建。威卡有历史团体与师承；个人施术多为自学／课程／共同体传承；没有单一活传统。

现代巫术不是单一传统，是一组当代实践：

- **威卡**：20 世纪中期公开出现的现代宗教／巫术传统；有团体、师承、入门与 degree 的分支，也有独修与折衷实践。不是所有威卡都加入 coven，也不是所有巫术都是威卡。
- **现代个人／折衷施术**：蜡烛、草药、香、愿望罐、纸符、小型综合仪式；可以独立于任何宗教，也可以嵌在个人信仰里。
- **神祇参与的现代融合实践**：把所奉神祇、个人虔敬与当代施术方法结合；不同文化的神祇实践有各自的语境与授权边界。
- **容器施术**：现代愿望罐／施术瓶，与历史上的防护／反巫术瓶共享容器形式，但用途与做法不同。

## 它是什么

围绕一个具体目标，把材料的性质与对应、语言、动作，以及操作者的意向，组织成一次施术。威卡还给这套工作加上宗教关系、季节节律与仪式共同体。

**意志放在哪一层**：威卡可以放在宗教关系、仪式表达、具体结果三层；个人／折衷施术多为实用技法；神祇融合是关系＋实用技法；容器施术是实用技法。

## 它不是什么

不是「随便混合」；不是「所有蜡烛／草药都是威卡」；不是「所有威卡都加入 coven、按 degree 推进」；不是「现代 spell jar 等于历史 witch bottle」；不是「可以跳过材料安全与文化语境」。

## 操作形式（按支线）

| 支线 | 实际在做什么 | 主要要求 |
|---|---|---|
| **威卡的宗教与仪式实践** | 神祇关系、sabbats／esbats、circle／quarters、祭坛与工具、仪式剧、个人或团体仪式 | 宗教体验、仪式投入、周期性实践、群体或独修的选择 |
| **现代个人／折衷施术** | 蜡烛、草药、香、愿望罐、纸符、小型综合仪式 | 意图具体化、对应取用、材料与动作的组织 |
| **神祇参与的现代融合实践** | 祈祷／供奉与具体施术结合；神祇关系进入日常工作 | 关系与工作的协调、语境与授权 |
| **容器施术** | 现代愿望罐／施术瓶；历史防护瓶的阅读与明确改编 | 组合、关系判断、材料安全、历史区分 |
| **传统神祇的现代融合** | 传统神祇＋现代施术；与虔敬／重建交叉 | 先分清虔敬、重建与融合施术（见 [现代异教与传统复兴实践](nature-religion.md)） |

> 四方、圆圈、工具等是常见的仪式语言，不是所有威卡传统都一样；coven 与 degree 只属于部分团体传承支线。独修、折衷与团体实践都是合法入口，匹配要看具体支线。

## 威卡内部可以有的三种收获

- **宗教性的收获**：与神圣建立关系，形成生活中的周期与意义。
- **仪式性的收获**：让语言、身体、空间、象征和意向共同参与。
- **实用施术的收获**：围绕具体目标选择和组织方法。

这三种可以在同一个人身上同时存在，也可以有明显侧重。报告要写「哪一面被推到前面」，不写「威卡适合你」。

## 基本功与门槛

- **核心能力**：意图具体化、材料／对应知识、基本仪式结构、安全操作、记录。
- **硬门槛**：无特定技能硬门槛；**物理安全条件**（火、烟、化学品、精油、摄入）是硬条件；**封闭文化传统的授权**是硬门槛。
- **必要能力**：火／烟／通风安全；植物识别与毒性；宠物／儿童安全；容器压力／霉变；伦理与法律边界；不承诺医疗、法律、金融结果。
- **加分能力**：手作、配色、草药学、写作、烹饪、园艺、表演、仪式主持。
- **适配条件**：愿意接触材料；能接受象征／宗教语言（威卡支线）；愿意学语境（神祇支线）。
- **可补偿短板**：对应→书／老师；手作→练习／工具；仪式结构→脚本；文化语境→学习／授权。
- **不可补偿短板**：没有封闭传统的授权→不要做那一支；没有安全的火／烟／材料环境→不要做相应操作；医疗／法律／金融危机→不要用施术替代专业帮助。

## 五种个人长处（匹配的重点）

| 长处 | 在施术中的具体表现 |
|---|---|
| **意图的具体化** | 能抓住这次究竟要推动什么，把模糊的愿望整理成一个有中心的工作。 |
| **对应取用与材料判断** | 理解某种材料在这次工作中的作用，能根据实际情况作出选择。 |
| **材料、语言和动作的组织** | 能让各个环节彼此说明，共同指向一个目的。 |
| **操作中的意向调动与保持** | 做具体动作时，注意、情绪和愿望能进入其中，形成集中而明确的投入。 |
| **因地制宜的构思** | 面对有限材料、时间和空间，仍然能组织出一套有条理的做法。 |

手工、配色、收纳、记录是辅助能力；卡的主体是构思与施行。

## 相关体系／实践实例（不是新卡）

- **Hoodoo／conjure**：蜡烛、草药、honey jar 等媒介有自己的非裔离散历史、共同体与授权；不是威卡的附属，也不是免费素材。主卡见 [Hoodoo／Conjure／Rootwork](hoodoo-conjure.md)。
- **历史 witch bottle**：17 世纪英格兰的防护／反巫术／疗治实践，常被藏在建筑中；与现代 spell jar 共享容器形式，但用途与做法不同。
- **传统多神异教／虔敬**：重建供奉、祭仪、节庆与神祇关系在 [现代异教与传统复兴实践](nature-religion.md)；本卡只处理「传统神祇＋现代施术」的融合支线。
- **混沌魔法**：作为一种施术取向纳入本卡，不是威卡分支。先整理互相拉扯的意图，把信念与象征作为可调整的实践资源，借 sigil、状态工作等组织操作，再通过记录回看、修正方法。
- **Thelema／现代秘传课程**：各自保留主卡；与本卡同属「现代」语境，具体能力要求另按其方法评估。

## 内部支线（谁容易上手，谁吃紧）

- **威卡宗教／仪式**：适合宗教体验、季节节律、群体仪式型；吃紧的是不愿进入神祇关系或团体结构的人。
- **个人／折衷施术**：适合意图清楚、材料敏感、喜欢自己组合的人；吃紧的是需要完整体系或师承才敢动手的人。
- **神祇融合**：适合关系型＋实用型；吃紧的是不愿处理文化语境与授权的人。
- **容器施术**：适合组合与关系判断型；吃紧的是材料安全与历史区分。
- **传统神术融合**：适合已有神祇关系的人；吃紧的是把虔敬、重建与施术混成一件事的人。

## 它给什么

实用结果、材料连接、仪式能力、宗教／季节生活（威卡）、一个初学者能上手的入口；代价是材料准备、安全操作、文化语境与持续练习。

## 授权与边界

威卡分支的师承／degree 不能自学冒充；独修与折衷是合法路径，但不要声称未经授权的 lineage。Hoodoo／conjure、Santería、Vodou 等有各自的共同体、历史与授权，不要把其媒介当成免费素材；不挪用封闭传统；不把神祇当工具。

## 安全性

- **按实际动作区分**：纸上设计与材料操作分别处理；蜡烛、香、草药、精油、化学品、密封罐各有具体条件；摄入、大量焚烧与封闭空间另看暴露风险，封闭传统另看授权。
- **状态工作**：按具体方法与强度另评；高强度 gnosis 不属于普通入门要求，不由符号设计或日常施术的低门槛推定其适合度。
- **主要风险**：火／烟／烫伤；精油与草药毒性；过敏；宠物／儿童误食；密封罐压力／霉变；文化挪用；把结果当医疗／法律／金融保证。
- **安全条件**：通风、灭火、手套、植物识别、剂量、宠物／儿童隔离、记录、停止条件。
- **不适合**：无法保证火／烟安全的人；有幼儿／宠物且无法隔离的人；正在医疗／法律／金融危机中的人；没有授权却想做封闭传统的人。

## 学习入口（可选）

从一个安全的单点开始：一支蜡烛＋明确的意图＋记录；或一个简单的季节观察；或一个不用火／不用摄入的愿望罐。先读可靠来源，再决定是否进入威卡团体或课程；不要一次买长期课程，不要摄入任何东西。

## 常见误读 / 相邻区别

威卡 ≠ 所有巫术；蜡烛／草药 ≠ 威卡专属；spell jar ≠ 历史 witch bottle；对应表 ≠ 固定配方；现代折衷 ≠ 没有语境；神祇融合 ≠ 可以把封闭传统自由混搭。

## 画像压力测试

先选个人施术、威卡宗教仪式、容器或其他具体支线，再看「抓住目的 → 选择材料与方法 → 组织动作 → 调动并保持意向 → 收尾回看」。构思、材料取用、现场投入和因地制宜可以分别成为主长处；把它们接到实际工作里，看下一环由什么能力承接。宗教认同、材料条件与个人能力分别说明。
