# 灵视与通灵（Seership／Channeling）

> 灵视与通灵分两层；梦境占卜归入灵视渠道。这张卡是「接收类」实践，不是内修；内修见 [内修与默观](inner-work.md)。

## 体系定位与传承

**路径类型**：半建立（能力家族，不是统一传统）。有课程、团体与个人实践；没有统一体系，边界、伦理与安全差异很大。封闭宗教中的通灵／附体另按该传统授权处理，不并入这张卡。

灵视与通灵是两层：

- **灵视**：接收的**渠道**——梦、图像、场景、象征、印象。
- **通灵**：接收的**关系与对象**——灵体、祖先、指导者、自然能量；恍惚与附体视传统。

## 它是什么

通过梦、图像、场景、象征、印象、言语、书写或恍惚接收信息；再记录、复盘、辨别、解释，并用到实际处境。核心不是「看到什么意象」，而是「能不能从这个渠道收到信息，以及收到之后会不会用」。

## 它不是什么

不是内修；不是「全是想象」；不是「每个梦/符号都是讯息」。

## 意志放在哪一层

- **灵视渠道**：技法＋接收；训练的是注意、意象、记录与关闭。
- **通灵关系（可选）**：关系＋接收；还要看对象、边界与授权。
- **解读与应用**：训练；收到不等于会用，符号解读与复盘要另练。

## 操作形式（按渠道与关系）

| 支线 | 实际在做什么 | 主要要求 |
|---|---|---|
| **梦境接收（孵梦／梦境占卜）** | 睡前设定、记梦、系列梦、解释；把夜间意象带入白天 | 记梦、复盘、符号解读、边界 |
| **图像／场景灵视（含 scrying）** | 主动进入或接收图像、场景、内在视觉 | 意象稳定、边界、关闭 |
| **象征／印象接收** | 符号、感觉、片段印象 | 保留、记录、辨别 |
| **转译（书写／绘画／言语）** | 自动书写、绘画、口述或听到讯息 | 转译、记录、边界 |
| **灵体沟通／媒介（可选；恍惚／附体视传统）** | 与实体／祖先／指导者沟通；不一定需要通灵／附体 | 边界、辨别、授权、关闭 |

## 基本功与门槛

- **核心能力**：接收灵视信号、记录／复盘、符号解读、辨别、边界、应用。
- **硬门槛**：**条件性——能否接收到信息**。这不是人人都有；没有接收，不要硬走通道角色。**梦境支线另需记梦**；通灵关系另看。
- **必要能力**：复盘／记录、符号训练、辨别。
- **加分能力**：写作、绘画、语言能力、恍惚、群体引导、灵体沟通／关系（可与灵视渠道配合，不必进入通灵／附体）。
- **适配条件**：能容忍不确定，多意比喻；愿意复盘；不把信号当做信息本身。
- **可补偿短板**：解释、记录、符号训练可以学；接收本身较条件性。
- **不可补偿短板**：完全接收不到→不要硬走通道角色；不喜欢复盘→灵视收益会低；心理危机／精神病性症状→不做深度灵视／通灵。

## 个人长处（匹配的重点）

| 长处 | 在本卡中的具体表现 |
|---|---|
| **接收灵敏度** | 能稳定从梦、图像、象征或印象里收到内容，而不是只靠想象补。 |
| **意象／梦境保留** | 能记住并保留收到的画面、片段与梦，不让它当场散掉。 |
| **符号解读** | 能把符号、场景、印象转成可理解的意义，而不是停在「很神奇」。 |
| **复盘与记录** | 愿意记录、回看、校正；能从 series／重复出现的符号里看出线索。 |
| **辨别与边界** | 能区分想象、投射与接收；知道何时关闭，不把讯息当绝对命令。 |
| **应用与落地** | 能把收到的信息用到具体处境，而不是只收集体验。 |

> 接收吃天赋；使用收到的信息要训练。报告要分开写「能不能收到」与「会不会用」，不要合成一个「灵视天赋好不好」。

## 内部支线（谁容易上手，谁吃紧）

- **梦境型**：记梦好、愿意复盘；吃紧的是不喜欢记录、或完全记不住梦。
- **图像型**：内在视觉、场景感强；吃紧的是心盲症或视觉化困难。
- **符号型**：对符号、印象敏感；吃紧的是过度联想、缺少验证。
- **转译型**：书写、绘画、言语顺；吃紧的是把转译当原文。
- **恍惚／媒介型（视传统）**：能进入意识状态改变，如浅恍惚、深度专注、自动书写、扶乩／降神／附体；吃紧的是边界、授权与辨别。不走这条线的人，仍可通过灵视、梦、符号与灵体沟通。

## 它给什么

指引、材料、关系、理解；也可能给一种「与不可见者保持关系」的生活方式。代价是训练、复盘、边界与不确定性。

## 授权与边界

- 半建立；没有统一体系。封闭宗教中的通灵／附体以传统授权为准。
- 心理健康与安全优先；不诊断、不替人做决定；不把讯息当绝对命令。
- 不邀请没有边界的实体；不把「收到」当成「一定真」。

## 安全性

- **按实际动作区分**：梦境日记、符号学习、图像练习与深度灵视、媒介或恍惚分别看强度、调节和退出条件。
- **主要风险**：睡眠、情绪、边界、实体依附、心理；把想象当讯息；把讯息当命令；精神疲劳，精神消耗。
- **安全条件**：grounding、记录、复盘、关闭、同侪／师承、可退出。
- **不适合**：完全接收不到却硬要走通道角色的人；不喜欢复盘的人；正在心理危机／精神病性症状中的人；想跳过边界直接通灵的人。

## 学习入口（可选）

先从梦境日记、符号学习和轻量图像练习开始；做记录与复盘，不邀请实体、不进入深度恍惚。看自己能不能稳定收到、能不能区分想象与接收、关闭后是否稳定。若完全收不到，不要硬走通道角色；可以转做记录、解释、研究或艺术转译。

## 常见误读 / 相邻区别

灵视 ≠ 内修；灵视 ≠ 全是想象；灵视 ≠ 必须恍惚；灵视 ≠ 每个梦都是讯息；灵视 ≠ 绝对命令；通灵 ≠ 没有边界。

## 画像压力测试

按具体渠道逐项看「出现 → 保留 → 辨识 → 转译 → 应用 → 退出」，对象互动另列。写清内容在哪里出现、哪一步已经能完成、哪一步确实吃紧；梦境、内在视觉和外部符号解读可以有不同画像。接收鲜明、解释准确、来源判断与实际可靠性分别讨论，不从表达强推接收强，也不从缺少某个渠道否定整类工作。

正文写此人的长处怎样完成任务；断点与补充条件只在材料支持时写入。牌证、竞争解释与未覆盖项放入 `AUDIT.md`。
