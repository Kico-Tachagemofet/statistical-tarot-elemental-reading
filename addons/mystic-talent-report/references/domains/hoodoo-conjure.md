# Hoodoo／Conjure／Rootwork（美国南方非裔民间法术）

> 本卡属于「民间／rootwork」能力家族；与 [Vodou](vodou.md)、[现代巫术与日常施术](modern-witchcraft-daily-practice.md) 交叉引用，各保留自己的传统语境。

## 体系定位与传承

美国南方非裔的民间法术传统。它通常不被视为一个有独立神系、祭司与统一入门的宗教；许多实践者同时是基督徒，也有人不带宗教身份。知识通过家族、社区、实践者、店铺、书籍与师承传播，没有统一中央组织或统一入门。

## 它是什么

通过根草、蜡烛、油、粉、容器、mojo bag、祷文与言语，处理保护、清理、运气、爱情、金钱、工作、疗愈、正义等具体事务；以实用工作为主。

## 它不是什么

不是 Vodou；不是 Louisiana Voodoo；不是 Wicca；不是「Vodou 轻量版」；不是没有社区边界的自由取用。

## 意志放在哪一层

- **实用技法**：大多数工作围绕具体事务、材料与做法。
- **独立辨事与施作**：把知识落到具体处境；不是个人秀。

它不是一条「道路本身」；是一组可学的民间实践。

## 操作形式（按支线）

| 支线 | 实际在做什么 | 主要要求 |
|---|---|---|
| **材料操作** | 根草、矿物、油、粉、baths／washes；材料与具体对象的关联（姓名纸、personal concerns、相关物件） | 识别、选材、剂量、安全、目的匹配 |
| **蜡烛与容器** | 蜡烛 dressing／fixing、颜色、petition；honey jar、vinegar jar、bottle、mojo bag | 意图、材料、组合、封存／维护、火的安全 |
| **祷文与言语** | 诗篇、祈祷、petition paper、name paper、口头宣告 | 言语投入、传统知识、边界 |
| **辨事与施作** | 辨认问题、占问（按具体传统）、选法、施行、根据后续调整 | 知识、判断、经验、边界 |

## 基本功与门槛

- **核心能力**：意图具体化、材料／选材知识、组合与施行、言语／祈祷、辨事与选法、持续维护。
- **硬门槛**：没有统一入门或统一技能硬门槛。独立辨事与施作需要长期知识、判断与实践经验；某些社区位置另有师承与社区边界。这些是参与／经验条件，不是能力短板。
- **门槛按支线**：材料操作——低；蜡烛／容器——低到中；祷文／言语——低到中；辨事与施作——高（知识、判断、经验、边界）。
- **必要能力**：材料安全、剂量、记录、边界；伤害性／控制性工作不在本卡范围。
- **加分能力**：更广的草药学知识、手作、植物／材料知识。
- **可补偿短板**：草药知识、蜡烛技术、组合、祷文可以学；经验和判断靠长期实践。
- **不可补偿短板**：无特定。

## 个人长处（匹配的重点）

| 长处 | 在本卡中的具体表现 |
|---|---|
| **意图的具体化** | 能把模糊愿望整理成有中心的工作，知道这次要推动什么。 |
| **材料与选材判断** | 看得出根草、矿物、油、粉、蜡烛在具体目的里能承担什么作用，并能安全选用。 |
| **组合与施行** | 能让材料、语言、动作、容器彼此说明，共同指向一个目的。 |
| **言语／祈祷投入** | 能通过诗篇、祈祷、petition、口头宣告把注意与意图集中起来。 |
| **辨事与选法** | 能把传统知识与眼前的具体处境连起来，判断哪些做法合用。 |
| **持续维护与记录** | 能照管需要维护的工作，记住使用条件、后续表现与结束方式，并据此调整。 |

> 这些是不同的长处；一个人可以很会选材与组合，却还在学独立辨事；也可以祷文很强，但持续维护较弱。报告要写「哪一支」，不写「适不适合 Hoodoo」。

## 内部支线（两种投入方式）

- **上手／审美／自然型**：喜欢简单、快速上手、有美感或亲近自然的体系；网上资源多，容易从蜡烛、草药、jar work 开始。长处通常在材料感、动手、仪式氛围；风险是停在配方和 kit 层面，把 Hoodoo 当成一套好看的日常实践。
- **效果／深入型**：追求具体结果与转化；需要对体系、材料、辨事、选法有深入理解，能根据处境灵活取用。长处通常在辨事、组合、持续维护；风险是急着要结果、跳过材料与社区语境。

两种不是高低；上手型可以后来转深入，深入型也要先经过具体材料与做法。

## 它给什么

实用结果、材料连接、言语／祈祷的力量、一种可日常操作的实践；代价是学习材料、伦理边界、结果不确定。

## 授权与边界

- 没有统一入门或中央授权。
- 与 Vodou、Louisiana Voodoo、Wicca、自然魔法分开；可交叉引用，不合并。

## 安全性

- **按实际动作区分**：材料、蜡烛、烟、精油和草药分别核对火、毒性、过敏与摄入条件；墓地或灵体工作另看具体现场和操作。
- **主要风险与条件**：火、烟、毒性、过敏、宠物／儿童、处置；不做伤害性工作；不承诺医疗／法律／金融结果。

## 学习入口（可选）

先读可靠资料，学历史、社区边界与材料安全；从保护、清理、祝福等非伤害性工作开始；不要买 kit 自称已经掌握；有社区／师承时按传统学习。

## 常见误读 / 相邻区别

Hoodoo ≠ Vodou；Hoodoo ≠ Louisiana Voodoo；Hoodoo ≠ Wicca；Hoodoo ≠ 「Vodou 轻量版」；Hoodoo ≠ 好莱坞「voodoo」；Hoodoo ≠ 没有社区边界的自由取用。

## 画像压力测试

将画像放进「辨事 → 选材选法 → 组合施行 → 维护 → 回看」。材料敏感者可以在用途和组合上发挥，辨事强者可以在具体处境与传统知识之间作选择；接着看这份长处怎样进入持续维护。传统知识和社区关系是实践条件，缺口是否成为此人的吃紧点，按画像与实际参与条件分别说明。

正文写此人的长处怎样完成任务；断点与补充条件只在材料支持时写入。牌证、竞争解释与未覆盖项放入 `AUDIT.md`。
