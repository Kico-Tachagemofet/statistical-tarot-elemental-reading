# 领域匹配：让固定画像走完一段实际工作

能力画像完成后才读本文件与 `field-affinity.md`。保留七模块、接收矩阵、商业轴中的原判断；灵视题同时承接画像冻结前按 [四组框架](seership-frameworks.md) 形成的 K1–K4 及其功能、模态、稳定度、准确性和来源范围。领域知识负责说明这些功能进入何种工作，不能反过来改牌义或取消已有的符号层支持。喜乐宫只按 `field-affinity.md` 解释领域与官能的亲和条件。

此时给用户选择 3–5 个体系；已有明确选择就沿用。未选择时，直接选画像最能展开具体判断的 3–5 个。先写选中体系的哪条支线，再做压力测试；用户关心的领域即使吃紧，也照常展开。默认选择须在 AUDIT 留下一句理由。

## 六条共用任务链

| 链 | 实际工作 | 重点看哪一段衔接 |
|---|---|---|
| 接收型 | 进入／自然出现 → 保留 → 辨识 → 转译 → 结束与恢复 | 先看已有输入、承接或领会功能，再细分有材料的渠道及保留、处理条件；主动构造与自发出现分别登记，模态未知不取消功能 |
| 释义型 | 定问 → 读材料 → 联系与组合 → 取舍 → 成答 | 细读、联想、整体判断和表达能否接在一起 |
| 施行型 | 定目的 → 选法 → 准备 → 制作／施行 → 使用与维护 | 会选、会设计、会动手、能在现场推进及后续维护分别看；祝圣仅在所选方法包含时加入 |
| 体系与内修型 | 读懂 → 内化 → 练习 → 观察 → 整合 | 知识怎样进入注意、情感、身体与日常；按技法取其中必要环节 |
| 关系与文化型 | 理解语境 → 参与 → 回应与照料 → 持续 | 人侧的投入、协同和关系连续性；特定职分才另接资格与传授 |
| 表达与商业型 | 定位 → 表达与包装 → 组织交付 → 经营 | 吸引注意、讲清服务、做成交付、控制成本与持续经营分别看 |

任务链表示实践要求，不是此人已发生的事件顺序，也不证明他已完成或缺少某一步。一个体系可以调用多链，按具体支线合并、循环或省略无关节点；正文不用六种标签排版。同元素牌仍只并列辨形，跨元素的作用方向与实际时间分别核对，不能借任务程序补出个人先后。

## 每次压力测试怎样形成结论

从画像提取有内容的能力句，例如“擅长维持既有结构，发起新工作吃紧”，不要只拿“持修强”。写清：**这项功能 → 在哪一支的哪项工作中发挥 → 哪个衔接有支持、相反材料或尚未覆盖 → 哪种条件会改变结果。** 关系、声音、身体、手作只在实际需要时单看；不能用元素占比替它们作答。未覆盖须保留具体层级，不由缺模态、来源或履历判整个功能缺失；领域门槛只说明工作要求，未核实的个人条件不触发“不适合／不能走通道”的排除。

每个重点领域形成一段有主旨的判断：先写长处在这里能做什么，再写有依据的断点与条件。没有断点证据就不配一个短板；能力相同，在不同领域应呈现不同后果。入门、深入、服务只展开与问题有关的位置，不把人人都要学的基础写成天赋。

未涉及但会改变路线的环节，可给一个能区分解释的小试验。例如，结构理解已明确、材料制作未知：先按公开图样制作无施术功能的纸样，比较读懂关系与完成布局是否同样顺畅。写明观察哪一步、什么结果会改变判断；不先断言练习一定能补好。涉及传统资格或复杂状态工作的条件，采用现有实践记录、指导者反馈或公开资料比较，不以现场冒险证明适性。

后台每个领域留：主卡／支线、调用链、画像依据、接住环节、有相反材料或未覆盖的具体层面、条件、待试验项。正文保留具体判断与必要条件；所有面向人的灵视判断，包括强项、限制和适配，都以“你可能……”或“你或许……”开句，不扩大冻结画像的范围。统计、竞争解释和 open threads 放 AUDIT。

## 虚构短例：结构强，发起弱

以下仅示范推导，不是个人案例：假定画像已明确“能把复杂规则整理成可用步骤，沿现有安排持续完成；独立提出新目标与启动工作吃紧”。

进入卡巴拉对应研究，这个人能把零散材料放回地图，并用固定课题继续深化；开放式探索需要额外的定题支持。进入古典护符制作，同样的长处会落到条件排序、备料和完整施作，成熟方案能提供起点；独立选定用途仍是断点。进入牌卡占卜，题目与抽到的材料已经给出起点，结构能力可以直接用于组合与收束。三个领域用的是同一份画像，工作后果各不相同。
