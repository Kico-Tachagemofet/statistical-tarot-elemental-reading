# 牌义与占星校准

入口步骤 1 读取本页及相关牌的完整正文，提取动作、条件与属性；步骤 2 用这些属性细化元素形态与本题功能，步骤 3 合议全场关系，步骤 4 收束能力画像。本页提供功能翻译和关键对照，喜乐宫在领域匹配层使用。

## 一条结论怎样长出来

1. 从牌义写动作：谁在保存、构作、施压、解释、退离？做到哪一步，限制是什么？阶段性只保留在单张牌的原义内容中；花色序列不能排列此人的事件，同元素牌不互为前因后果。跨元素作用方向与实际时间另按 [论断与关系](inference-contract.md) 核对。
2. 用性质解释这个动作怎样发生：火热干，风热湿，水冷湿，土冷干。热推动改变，冷收拢保持，干持形和区分，湿相接和随接触改变。冷也有作用力；水有运动性；风本身没有火那样明确的方向。原统计 skill 的三性质、轻重与元素本体保留；具体人事推断按本报告的 [元素应用口径](element-application.md) 使用。
3. 旬星提供自然功能，星座提供元素、模式与传统守护条件，再看牌义给出了怎样的结果。例如“土星的限制在射手双体火中表现为强压”须由权杖十落实，不能单从土星射手推出来。大牌按自身行星或星座对应，不补旬星。
4. 回全场看这项功能得到什么承接、在哪一步受阻，再落能力。共用行星或性质只提供可比较处；真正的连接要说明两端动作怎样作用。保持量／质区别；风少时检查是否有火统摄具体思路的依据，不自动判定已被纯化。
5. 写具体长处和断点，如“能细究材料，但重要问题被做成许多小问题”；模块名只负责组织。牌、元素、旬星是同一证据的展开，不是三票。

## 七曜与星座：用于细化动作

下表的自然功能来自传统资料；“本题怎么用”是能力分析的转译。行星气质与花色性质分栏理解：月亮并非固定冷湿，水星也不是固定风。月亮射手不会把权杖九改算水牌。

|---|---|---|
| 太阳 | 统御、显明、生命中心；热而偏干 | 看主旨怎样被确立或显现；也可能照出外部条件，按牌义定主体 |
| 月亮 | 生成、滋养、身体、变化、感受与传递；湿性为主 | 看察觉与回应、状态维持和变化；主动处理与受情境影响须分清 |
| 水星 | 语言、计算、推理、解释、交换、技巧；性质可变 | 看辨别、重组、命名和转译；细节聪明与整体判断分别看 |
| 金星 | 和合、欲望、愉悦、调配、美与艺术；温和、湿性为主 | 看材料怎样结合、形成可享用的形式；和合与兑现分别看 |
| 火星 | 切断、竞争、勇武、强力行动与技艺；热干 | 看突破、切分、制作和施力；投入力量与完成目标分别看 |

本位联系开端与季节转折，固定联系维持与坚固，双体联系双重、交替与转换。先说明**什么**被发动、维持或转换，再用模式细化。守护星说明所处环境由哪种功能组织；塔罗没有该守护星的真实落点，另有同星牌也不直接成为占星定位星链。

**尊贵只在这里区分一次：**`decan_dignity` 是旬星在整个星座中的入庙／入旺／失势／落陷条件；`detriment` 为失势，`fall` 为落陷，不混译。“无主要尊贵或失势”不等于无作用。Book T 的 *well/ill dignified* 按左右邻牌及元素关系判断强弱，且加强可以加强好或坏的牌义；正逆位是另一输入。统计五堆没有左右邻位：保留原典分叉，由全场实际支持或牵制收束，称“全场支持／牵制”，不伪称算得 Book T 邻位尊贵。正逆比例按本报告 [入口](../SKILL.md) 的统计口径只作方向探针，不换算为能力或成功率，不凭多数逆位选择负面分支；也不拿正位、旬星入旺直接开启好分支。旬区间也不等于真实行星度数，不补界、昼夜阵营或相位。

## 七组必会的差别

以下“改判”用于检验换牌后是否保留了具体内容差别，是相应语义源与题型下的功能候选，不是每张牌必须套用的个人结论。作者分支仅在对应牌义包实际启用时使用；关闭时按本次 Book T 材料，不借比较例暗补作者解释。实际功能由原问、完整牌义与全场材料决定，按 [能力依据与优先级](capability-evidence.md) 比较主线；灵视项已有支持时再用 [四组类型说明](seership-frameworks.md) 细分方式。面向人的灵视判断仍以“你可能……”或“你或许……”开句。

### 1. 权杖九／十：守得住与压得紧

**属性：**均为热干火、射手双体、木星守护。九＝月亮射手 10–20°，十＝土星射手 20–30°；两者均无主要星座尊贵或失势。

**共同动作与分叉：**都有强力与对抗。九是稳定而难撼的力量，可能有技巧地施力、争斗后取得进展、恢复，也有顽固。十是强横施压，可能因先前过度自利而遇到难控对抗；另有慷慨、无私和自我牺牲分支。月亮的变化与恢复、土星的限制和重压在牌义中取得不同形状。

**改判与能力：**九换十，持修由“抗扰后能接着做”改为“以持续施压撑住工作，代价和对抗进入主线”。牺牲或控制的具体归属看全场谁承担、谁获益；九的恢复不能搬给十。定向施行、持修调节都要随之改写。

### 2. 圣杯六／七／八：开始、未兑现与不再延续

**属性：**均冷湿水。六＝太阳天蝎 10–20°；七＝金星天蝎 20–30°、金星失势；天蝎固定、火星守护。八＝土星双鱼 0–10°，双鱼双体、木星守护；六、八均无主要星座尊贵或失势。

**共同动作与分叉：**所得或愉悦能否保留。六是稳定增益的**开始**，并有自我主张过甚而起争执的分支；七是看似获胜、承诺未兑现，或所得因未跟进而未保留；八已有短暂所得，却失去兴趣、拿到后放下，没有进一步结果。

**改判与能力：**六可支持开始有所得、尚未圆满的形态；换七须辨明本题中什么尚未兑现或未保留，不预设人的辨识和跟进已经脱节；换八检查所得与继续兴趣的关系，不自动断定加工能力不足。三者都不单凭水象指定梦境或视觉渠道，模态未定也不取消已有支持的体验或承接功能。金星失势可细化七的和合条件；原义中的“未跟进”仍须保留，但不能越过对象与作用证据，直接指认为反馈、记录或验证缺失。

### 3. 宝剑六／八：处理过去与困在细部

**属性：**均热湿风。六＝水星水瓶 10–20°，固定、土星守护，无主要星座尊贵或失势；八＝木星双子 0–10°，双体、水星守护，木星失势。

**共同动作与分叉：**都有耐心和用功。六是在忧虑困难之后取得结果，劳动与耐心有效；八把过多力量用于小事，细节研究认真，却可能遗漏主旨，部分照料与别处混乱并存。

**改判与能力：**六换八，不能继续写“能把复杂问题处理清楚”，应改为“能钻研局部，尺度和优先次序容易失衡”。辨识收束与象征理解因此不同。木星失势只是这份扩展与主次问题的条件，不等于智力差。

### 4. 星币三／七／八：构作、回报与细工

**属性：**均冷干土。三＝火星摩羯 10–20°，本位、土星守护，火星入旺；七＝土星金牛 20–30°，固定、金星守护；八＝太阳处女 0–10°，双体、水星守护；七、八无主要星座尊贵或失势。

**共同动作与分叉：**都涉及物质工作。三建造、增加和开展交易，事情**尚待以后建立**，也可能逐利狭窄或追不可及之物；七许诺的成果不结实，投入多、回报少，零星所得无后续；八有技巧、勤劳和审慎，但可能小处精明、大处失算，保有小收益而缺乏开拓。

**改判与能力：**三换七，定向施行由能启动构作转成劳动与产出脱节；不可把有劳动写成已交付。三换八，突出细工和局部经营，整体建设另看。商业轴分别记录构作、投入产出和小额经营。杯六与币八同为太阳，前者开始增益，后者精细审慎，不能同给“核心判断力”。

### 5. 女祭司／月亮：内部研究与心境介入

**属性：**女祭司对应月亮；KicoCraft 用水说明内部知识处理。月亮牌对应双鱼（水／双体／木星），**不是行星月亮牌**。

**共同动作与分叉：**都可以内部活动强于外显。KicoCraft 女祭司储备知识、梳理关系、研究与解释；少展示可以是只给有限回应，也可以一时难言。月亮牌是事物引起的本能反应已经形成心境；明白事情仍可能难以面对，感受影响选择。Book T 前者强调涨落变化，后者强调不满、改变及错误分支；与作者正文分别留来源。

**改判与能力：**女祭司换月亮，知识处理长处不能沿留；转为看心境怎样参与辨识和行动。女祭司的沉默也不直接判表达障碍。两者均须另找渠道材料，才填接收矩阵的梦境或视觉格。

### 6. 女皇／魔术师：维持供给与重组呈现

**属性：**女皇＝金星，KicoCraft 土；魔术师＝水星，KicoCraft 风。两张无星座和旬星。

**共同动作与分叉：**都调用已有之物。女皇调配、保留、供养资源，顾及持续基础，价值受损时可能防卫；魔术师取舍、重组、呈现，引导注意，既可凭技艺形成新解，也可能表达漂亮而理解不深。Book T 的女皇愉悦丰饶、魔术师技巧与智慧，分别由正文细化。

**改判与能力：**女皇换魔术师，从“能把资源安排成持续照料”移到“会把现成材料组织成有力呈现”。灵感生成可来自重组；知识积累和原创程度另看。商业轴从供给组织移到包装与表达，不互相挪用。

### 7. 节制／隐士：主动调节与独自维持

**属性：**节制＝射手（火／双体／木星）；隐士＝处女（土／双体／水星），均无旬星。

**共同动作与分叉：**工作仍在进行。节制围绕方向调节力度、比例和配合，知道怎样调与实际协调仍有距离；隐士凭已内化的知识经验独自处理，既能独做，也可能缺少协助，产出不等于满足最终标准。Book T 节制组合力量并产生作用，隐士有智慧与主动灵感；作者正文补出实施条件。

**改判与能力：**节制换隐士，从“能围绕目标调整作用”移到“靠既有积累独立续行”。持修可以是火的调节，也可以是土的沉淀；节制不自动证明已协调，隐士不自动证明商业成功。
