# 报告写法：先让人显形，再看他进入什么工作

将固定画像与领域测试写成有主线的中文散文。分析按牌义、元素、关系与模块展开；成稿按读者能辨认的做事方式组织，通常围绕几条主要判断展开，技术依据置于节末。

## REPORT.md

### 开头与章节

开头一段 2–4 句，直接回答原问：这个人的主要长处怎样工作，在哪种事情上显出来；有关键断点时说明它改变了什么。定调句须在正文中得到展开。

写每节前，从已固定的画像中提炼一句读者能认出或反驳的具体判断：**处理什么事情或材料、怎样做、产生什么可辨认的差别；有条件时，条件改变哪一步。** 例如，已有依据支持“细读可用、取舍吃紧”时，可以写“读一段材料时能指出许多细节，但要选出最能回答这次问题的解释，就容易把几个分支一起留下”。该例示范判断的精度，不是新对象的预设结论。

画像已有明确动作和对象，成稿就把它解释出来；如果只能留下“结构、承载、图景、收束”之类概括，却说不清本题中具体指什么，回查对应 A 项和牌义，修正或收窄判断后再写。具体情境可以示范已支持功能怎样应用，要标明“例如／放到……这项工作里”；它不补造个人经历、感官模态或新的能力。

正文先能力、后体系。每节围绕上面的一句判断展开：这个人怎样处理材料，这种做法带来什么，以及什么条件会改变结果。标题承担该节观点，术语和比喻在首次出现时通过具体对象与动作说明用途，随后保持指涉一致。利弊和分叉随实际材料分配，不必为长处配一个短板。

五堆分读、元素形态、关系记录、七模块和接收矩阵用于 AUDIT 覆盖分析，不逐层重放成 REPORT 目录。正文按主要判断选择必要依据，说明它为何支持本题的行为或能力；仅列牌名不能代替这一步。接收、商业、身体与制作细项按其实际分量融入。用户明确要求技术全盘时可另附分析部分，仍先让主要判断可读。

**每个面向个人的灵视判断都以“你可能……”或“你或许……”开句，承载画像中已收束的具体功能和范围。** 适用于接收、体验、连接领会、转译、加工、强项、限制与适配。灵视标题使用主题，个人判断放在正文；统计事实、牌义引文、方法定义与 AUDIT 支持状态照实写。

### 把领域测试写成实际工作

将同一份画像放入具体工作：读一份配方、处理一段文本、维持日课、整理经验或向客户交付。写清哪一步用得上哪项能力，怎样使用，到另一步时什么要求变了，已有材料支持怎样的结果或条件。这里的先后来自任务程序，不能反写成同元素牌的因果或此人已经发生的经历。

用户所选的每个体系都有自己的任务判断，可以独立成节，也可以比较实质不同的工作。同一能力再次出现时，新增的是它在该任务里的具体作用或后果；适合性由这段说明得出，不用能力标签反复替代。各体系的共同前提可合并说明，保留各自真正不同的接法。

正文保留已形成的判断，以及会改变当前路径的必要条件。模态、反馈、加工等各层按其已有判断分别呈现，详细未覆盖项记入 AUDIT。入口建议对应具体任务，有待尝试的做法注明其用途和待观察结果。

商业与实践分别展开定位、包装、交付、经营等实际能力。New Age 的经营角色按所问项目说明，个人实践按具体方法说明。

### 依据与收尾

每节末留一行：`技术依据：A2、A4；关键牌形与有用的元素／旬星说明；领域任务及喜乐亲和（若使用）。详见 AUDIT.md。`

统计、属性和详细推导留在 AUDIT。结尾落在最有价值的实践入口或需要辨清的问题。小练习按需集中说明：观察哪种现象、不同结果会怎样调整哪项判断；一次观察提供后续线索，不直接确诊原因。已无需要区分的解释时，不为完整格式另添练习。

## AUDIT.md

保留能回查关键判断的推导，依次包含：

1. 原问、任务与完成标准、材料范围、统计口径、牌义源及版本。
2. 五堆相关牌义、属性与强调程度；按框架充分展开的各元素无序形态谱及本题功能。
3. 有效关系的两端、共同对象或传递关系、作用与依据；另有时间材料时标明来源。记录合议后的元素状态与整场表现。
4. `profile_frozen`：A1…的对象、任务、核心牌义及全场依据、与其他主线的比较、范围和相关未定项。灵视项先保留本身的能力判断，再附有依据的 K 类型说明；模态、稳定度、准确性、来源与接收矩阵各据材料记录，商业细项和用户经验分别呈现。
5. 所选体系、具体支线／角色、调用的任务要求、画像如何发挥作用，以及条件和结果。宫位与喜乐的用途单列。
6. 有材料且会改变结论的竞争解释、未决项与针对性尝试。

## 交付前核对

完成成稿后对照四项目标，必要时修订对应段落：

1. **方法落实。** 各元素已按框架充分比较形态、强调程度、适用范围与张力；跨元素关系有两端及具体作用，实际先后有独立材料。
2. **判断一致。** 正文沿用画像中的处理对象、任务和结论范围，体验、理解、表达、加工及交付的具体区别仍清楚。
3. **层次分明。** 统计强调与功能支持分别表达，已支持的功能得到具体判断，相关未定项保留在各自层次。
4. **报告有效。** 暂去牌名、元素名与 K 类型名称，读者仍能复述主要判断：自己在处理什么、怎样做、差别或条件在哪里。仅剩能力形容词或抽象比喻的段落回查对应判断；读不清是缺少说明，还是判断本身缺少依据，分别修正。各体系呈现不同的任务后果；个人灵视判断逐句使用“你可能／你或许”，保留会改变其含义的条件。

报告应使读者看清“凭什么做事、怎样做、进入这里会怎样”。鲜明来自有依据的具体差别。
