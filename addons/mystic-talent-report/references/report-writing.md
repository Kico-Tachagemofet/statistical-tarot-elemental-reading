# 报告写法：先让人显形，再看他进入什么工作

采用有主线的中文散文：一句有力度的定调，4–6 个贴着材料生长的比喻小标题，每节一个生活判断，散文展开，技术依据置于节末。写法不依赖任何私人样本；不从历史案例移植个人结论。

## REPORT.md

### 开头

开头一段 2–4 句，先给这个人的运作形状：最有辨识度的长处怎样工作，主要力量在哪里接通，若有关键断点就点明。配置名可以帮助记忆，不必每份强造一个名号。用具体动作立住画像，如“把零散材料组织成便于他人使用的说明”；不用“感知敏锐、思维细腻、有潜力”堆成摘要。具体功能与范围沿用冻结画像，不借开头重新安排人物的发展顺序。

### 章节

正文先写能力，再写体系。默认 4–6 节，围绕 3–5 条主线组织；不按七模块逐一开栏。接收、商业与相关身体／制作细项有材料才占篇幅。重点体系可以各成一节，也可在一节中比较两种有实质差别的任务；用户选的每个体系都要有自己的实际判断。

每节先在草稿里定一个可让读者认出或反驳的生活判断，再围绕它展开。可用 HTML 注释保存：

`<!-- 生活判断: 本节最具体的一条判断；条件若有也写在这里 -->`

标题承担观点，不写“直觉整合：偏强”。比喻必须由正文动作撑住，不机械复用其他报告的配置名与比喻。“两端强、中段薄”“点火—经营—落槌”等发展比喻不能用来把同元素形态排成个人流程或持续能力诊断。也不为每节硬凑利弊配对。

一节通常完成三件事：先说这个人怎样做；再说这种做法带来什么；最后写它进入何种条件会继续通畅或卡住。条件可以是材料支持的现实要求；确有未决分叉时，只在该处保留差别，不把全篇降成谨慎说明。

**灵视正文的每个个人判断都以“你可能……”或“你或许……”开句。** 包括接收、体验、连接领会、转译、加工、强项、限制和适配倾向；同段新增判断也保留这一措辞，不能段首说一次“可能”，后面改成“你有／你能／你就是”的裸断。标题不另下确定的个人判断，可用“体验怎样形成材料”等主题。统计事实、牌义引文、方法定义和 AUDIT 支持状态照实写。非灵视内容不必机械加限定词；灵视的可能措辞仍须承载具体功能与范围，不能替没有依据的内容补证。

### 体系压力测试写进生活动作

让读者看到自己进入工作：读一份配方、处理一段抽到的文本、维持一项日课、整理一次接收、参加一次共同体实践、把内容交付给客户。不要把体系百科重写一遍。

写清“哪项工作会用到画像里的哪项功能，衔接需要什么条件”。任务程序不等于此人已经经历的先后。真实断点要落在动作上，如“能读出每一处细节，却在选择主解释时不断重开分支”；不写“需要提高辨识与执行”。入口建议必须对应这一步。没有依据的改善办法作为尝试，不写成已经验证有效的使用条件。

领域段以已经收束的判断为主句，说明具体功能在任务里怎样发挥；灵视个人判断仍用“你可能／你或许”，不要把整段改成“值得测试／需要检验”的清单。未覆盖的具体层面记录在 AUDIT，正文保留会改变当前路径的必要条件；不能把模态未知写成接收缺失，把反馈未覆盖写成验证最难，或把加工可用升级为长期交付已成立。小练习全篇最多 2–3 个，按需要集中收尾，不让每个体系都变成一轮验收流程。

商业线与实践线可以不同。呈现与包装强就明确说强在什么，不附带道德猜测；交付或经营另看。New Age 可谈具体市场角色，不用体验浓度作推荐理由。

### 依据与收尾

节末一行：`技术依据：A2、A4；关键牌形与最有用的元素／旬星说明；领域任务及喜乐亲和（若使用）。详见 AUDIT.md。`

这行让人能复核，但不堆 z/p、完整属性表、全部竞争解释。数字和完整推导在后台。结尾落在一两个最有价值的实践入口或要辨清的问题，不重复一遍所有章节，不强制添加免责段。

## AUDIT.md

保持足够复核，不追求把每个思考都写成文档。建议包含：

1. 输入目录、原问、抽取回执／统计口径、牌义来源与版本；合成材料明确标注。
2. 支撑主线的牌义动作、单牌内容中的阶段、条件分支及无序形态谱；冷热干湿与占星如何改变动作的解释；R 关系的两端、作用依据与独立时间来源（若有）。
3. `profile_frozen`：一句主线；A1…能力判断的对象、任务、支持与相反材料、邻接未知项；七模块覆盖。灵视题保留 K1–K4 各自的功能判断，分开可用性、显著度、模态、稳定度、准确性和来源；随后保留有材料的接收矩阵与商业细项。来源为用户经验的地方明确标注。
4. 画像之后的体系选择；每个体系实际支线／角色、调用的任务链、接住／吃紧／条件；宫位与喜乐的作用单列一两句。
5. 会改变结论的竞争解释、未覆盖内容、针对性的验收尝试。没有实际分叉不为凑格式制造。

## 成稿判断

一份好报告应能复述成“这个人凭什么做事，进入这里会怎样”。如果去掉牌名后只剩“敏感、聪明、有耐心、注意边界”，回到具体动作重写；如果段落只有技术词，把它们落实为人怎样处理材料与任务。鲜明来自有依据的差别，不靠添加纸笔有效、某年必发生、某对象必回应等新事实。
