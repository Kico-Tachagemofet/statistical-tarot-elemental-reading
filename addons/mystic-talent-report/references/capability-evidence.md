# 能力判断：先依据全盘，再区分类型

本页恢复能力判断的优先次序：**完整牌义 → 元素性质与占星细化 → 全场状态及关系 → 能力主线 → 已支持能力的类型说明。** 它用于入口步骤 3–4；四组灵视框架在这之后使用。

## 1. 先保留各元素实际在做什么

从每张牌的具体动作、对象、条件和统计强调出发，充分比较各元素的形态及全场表现。一般玄学能力问题可以涉及定向、施行、辨识、理解、表达、材料工作、持修、感知与接收；先由本盘决定哪些是重心。

火的立意、认领、主动洞见、裁定与施力，水的感受、愿望、受用与情境回应，风的联系、辨析与传达，土的实务、生成与制作，都保留各自的实际对象。元素框架解释这些动作怎样运行；各元素的具体牌义决定它们在本盘承担什么。

例如，增加并固化物质首先支持将已有事物做实；情境尚未锁定时，可以讨论实务推进与材料加工。只有具体对象已指向体验记录时，才进一步说明经验怎样被固定。受形、稳定、冷热干湿解释动作的方式，图像、梦境或身体感觉则由对应内容依据确定。

## 2. 把可能的主线放在一起比较

对每条能力候选写清：**做什么、处理什么、有哪些牌义与关系支持、被强调到什么程度、有哪些相反材料、在全盘排什么位置。**

比较按以下顺序进行：

1. **内容相关性。** 牌义是否支持这项功能本身，还是只说明情绪、愿望、准备、加工等相邻环节？直接说明该功能的语义及具体关系优先，性质词用于细化。
2. **强调与全场配合。** 结合相关牌的偏多、基线、偏少以及元素状态，判断该功能是突出长处、可用但非主项、受限，还是依据尚不足。丰富的描述或多个类型标签不增加分量。
3. **竞争解释。** 比较哪些一般能力或其他任务更完整地解释同一材料，明确为何将某条列为主线。相反材料与偏少形态实际降低或排除相应主导解释；另一种实现要有自己的具体牌证，才能保留该能力。

基线可以保留普通功能；显著长处由与该功能相关的突出形态及全场支持决定。偏少限制相应形态的主导程度，整体有无与其他实现一并判断。结论说明具体活动与后果，便于当事人在做事方式中辨认差别。

## 3. 灵视、感知与接收也使用同一套依据

在一般画像中先判断：本盘是否支持这类功能，它属于突出长处、可用但非主项、受限，还是尚未得到足够支持。判断仍来自完整牌义、性质、全场支持与牵制。

分别记录两类材料：

| 材料职责 | 怎样用于判断 |
|---|---|
| **感知／接收功能本身** | 具体语义或有依据的组合说明怎样感知、承接、显现或领会何种内容。它决定本项是否有支持，以及支持的是哪种能力。 |
| **周边能力与内容状态** | 有情绪、愿望、想象、刺激后的反应、概念连接、记录或制作能力，各按自己的对象形成判断；它们说明可能配合的环节。 |

从周边能力进入感知／接收判断时，要说明新增的那一步：哪项牌义或关系将普通回应指向了本题的感知活动。仅有周边材料时，结论就保留这些一般能力，灵视本项按已有证据收口。

采用本次实际牌义：明确的媒介式或主动灵感语义可以参与判断，其他牌形和具体组合也可以支持同类功能。这里以动作与作用为依据，保持多种实现方式；用户经验可另标来源用于校准，符号层推断本身可以成立。

一般加工在基线、内在内容丰富或思想联系清楚，分别是有价值的判断。灵视是否为长处，须回到与灵视本身相关的材料和全盘比较。具体模态、稳定度、准确性与来源在其对应层次另判。

## 4. 先固定判断，再交给类型页

在 `AUDIT.md` 留下简洁的能力依据记录：

> 能力与具体对象｜核心牌义及关系｜相关强调与全场支持／牵制｜与其他主线的比较｜结论及范围。

据此形成 A1…与 `profile_frozen`。灵视相关项已有支持时，再读取 [四组类型说明](seership-frameworks.md)，解释已判定能力怎样输入、体验、加工或领会。它承接本步结论，不增加能力证据或改变主线排序；类型结果附在相应 A 判断下面。

本项未定或受限时仍可描述已支持的一般感受、理解或加工能力。若用户要求探讨可能类型，按条件展开该局部讨论，保留上游的程度与范围。领域匹配以固定画像为依据。

检验判断时，暂去四组框架的名称：能力主结论仍应能由具体牌义、全场关系及比较完整说明。换掉关键牌或其强调状态，主线及任务后果应随依据变化。
