# 元素在能力问题中的应用口径

本页用于原统计塔罗方法卡与能力画像之间的翻译，随本专题主流程读取。
它保留原卡的元素本体、人的层与环境层、显现与内含镜头、规则来源及认领记录。
本专题调整的是从这些材料推到个人能力与行为的条件，不把改变后的读法伪称为原规则原意。

## 读取范围与本次变更

按入口解析的 `BASE_SKILL`，完整读取其 `references/water.md`、`earth.md`；四元素合议同时读取 `fire.md`、`air.md`、`properties.md`、`relations.md`、`combinations.md`。这七页均位于 `BASE_SKILL/references/`，不调用旧 SOP 的解读编排。
正文中的原典说明、实例与来源表仍属于原方法；本页只覆盖下面列出的应用推断。

| 原方法的应用规则 | 本专题怎样使用 | 判定成立还需要什么 |
|---|---|---|
| 水多会占满生活空间、挤压事务；与其他元素抱团易出问题（水卡 3–5） | 检查体验、反应或情境的显著度及占用范围；挤压、恐惧、逃避、冲突分别列为条件候选 | 具体形态怎样占用同一对象或任务，以及别的工作受阻的材料 |
| 水的愿望须由土承载（水卡 5、性质卡 7） | 当被分析对象确为需要现实兑现的愿望时，检查承载条件 | 先锁定这是愿望、兑现指什么；接收体验或已有理解本身不因此被判未成立 |
| 水少使意愿与计划因缺乏共鸣而落不到关系与利益（水卡 6） | 检查具体的承接功能是否受限 | 不能从低强调同时推出缺共鸣、缺体验、关系失败和利益落空 |
| 土多使视野收窄；土少代表落地条件、身体力行、持续实践不足（土卡 3、5） | 分别检查条件、实践方式与持续性；总量只给观察权重 | 每一项具体不足均需自己的牌义与关系证据，不能三项一并判定 |
| 土多而缺风火则资源未组织好；水土缺理性时因怕受损而憎恨（土卡 4、水卡 4） | 区分资源数量、组织状态与对威胁的回应 | 需有组织受限或具体恐惧回应的材料；资源多与内敛本身不证明这些心理机制 |
| 土无轻，轻快表象下仍有“根基未稳的现实负担”（土卡 9，已认领） | 保留土的重与实质；将“根基未稳”从必然断语改为待核分支 | 本盘关于基础不稳的材料；只有重时可体现积累、成本、承担或限制 |
| 火多使目标被托起而忽略日常；火少缺主动意愿或使风回浓（火卡 3–7） | 分辨动力强度、方向、作用对象及配合条件 | 忽略、空耗、缺动力或思路回浓均需相应形态；有动力与能贯彻分别判断 |
| 风多可直接断想法相互矛盾；风少而火在读作被纯化（风卡 4、7） | 两者在本专题均作需检验的关系假设 | 前者需辨明不兼容的内容，后者需火如何统摄具体思路的跨元素依据 |
| 风少且火少可断缺传达通道；火土同干缺湿则传不出去（风卡 8–9、性质卡 5） | 检查内容、媒介、接收对象与传递效果 | 牌义所支持的具体通路受限，不能只凭元素数量断别人无法理解 |
| 只有风没有火便发现不了新东西，只能重组（风卡 12） | 保留重组与发现的功能差别 | 对“只能”的排除须覆盖本盘其他可用实现；少某种火不能取消所有创造或发现方式 |
| 火的显现先及水，随后及风土（火卡 2）；组合卡的失衡倾向 | 保留为原方法镜头，分开检查作用关系与条件 | 不能据本体次序给当事人的事件排时间；跨元素关系按主流程的因果契约成立 |
| 花色高位偏多便是密度与压力集中，发端偏多便方向未锐（性质卡 8） | 保留积累位置以辅助辨质，具体动作与状态由整张牌定 | 数字序列不能当作此人能力成长、工序进度或未来事件的时间表 |
| 四类关系与火水、水土作用（关系卡 2、6、8） | 保留共创、两极、因果、背景及两两关系镜头 | 两端分别存在不够；须有具体作用依据；性质相对不自动排除实际配合 |
| 风土天然和谐、通常较好；水火易冲突、入局成长快（组合卡 5–6，含已认领规则） | 将好坏、冲突和成长分别变成组合候选 | 不能由星座主星共管直接推结果，也不能由元素对立直接推冲突史或成长速度 |
| 风火适合小事，大事须警惕耐力；各组合具有特定长处与失衡（组合卡 1–4、7） | 用任务需求检查本盘已成立的功能与条件 | 不按组合标签直接选路、评人格或定长期承担；正面特质同样需要牌义支持 |
| 偏少牌须排除该种元素主导的状态（各单元素卡的负偏差规则） | 保留其排除作用，锁定到该牌形态及其主导方式 | 查同功能是否还有别的实现；低强调、能力缺失与明确受限分开 |
| 顺流疏水、接触实践调土、火风调校等处理方法（各卡处理章节） | 在对应失衡成立后提出处理候选 | 说明要改变哪个已成立机制；不能先由总量假定失衡，再用建议反证此人有问题 |

以上是明确的专题应用调整，包含已被认领规则的条件化；不改写原卡及其来源表。
它们也不是取消失衡判断：有材料时仍须直陈失衡，材料只支持风险时便写触发条件。
原卡其他例子也按同一层级读取：本体描述用于辨质，人事表现须经过下述功能推断；不能用原卡直断句跳过专题口径。

## 从完整牌义到本题功能

先保留所用牌义的完整动作与限制，再用属性说明这些动作如何发生，最后提出本题的功能候选。
记录实际采用的牌义版本；Book T 与作者牌义有差异时，按主流程确定资料层，不能各取一半拼出最顺的故事。

1. **动作与对象。** 谁或什么在吸引、裁定、受形、积累、制作、消散？对象未锁定就保留分支。
2. **性质怎样体现。** 冷热、干湿、轻重与三性质分别说明推动、维持、轮廓、延展、空间和运动方式；落轴后原动作仍在。
3. **本题功能。** 这个动作能处理哪种任务材料，得到什么可辨认的结果？由两者提出功能，不按元素名直接分配职位。灵视／灵感题在画像冻结前按 [四组题型框架](seership-frameworks.md) 检查输入、内部体验、加工和连接；不等待最后选体系时才决定水是否参与内部处理。
4. **条件与限度。** 什么条件让该功能成立，什么材料说明受限，哪些只是没有被本盘强调？人的层与环境层未定时并列。

“方向明确”不等于判断正确，“可流动”不等于体验丰富，“持形”不等于完美打磨，“可连接”不等于翻译准确。
这些性质可以解释已辨明的动作，不能替缺失的动作或结果作证。
同一功能可能由不同方式实现；同一种元素也可能承担不同功能，功能表因此必须从本盘生成。

## 水：辨明承接的是什么

保留水卡的两层：人的情绪、感受、直觉反应与内部状态转换；环境的共有条件、情境、关系氛围与流动空间。
冷湿、晦暗、致密、运动与相对轻重用于辨认这些形态，水中可内含思路与动力。
“被动”指受形与回应方式，不直接判能力低；“晦暗”也不直接判内容不可理解。

| 本盘可能辨认的对象 | 分析方向 | 可形成的功能候选 |
|---|---|---|
| 正在发生的体验、感受或意象 | 有什么内容，怎样出现、延展或凝聚；是否已带可辨认的结构 | 承接、感受、情境呈现、经验材料；准确性与外部来源另看 |
| 已形成的理解在体验中的状态 | 当事人能辨明什么，是否愿意或能够呈现给他人 | 体验中的认识、涵养、内部理解；不先假定必须再靠某元素获得意义 |
| 可向往的情境、可能性或愿景 | 是多个可能并存，还是具体许诺；其对象与现实条件是否已锁定 | 展开可能、投入想象、形成期待；内容多不等于已兑现，也不等于必然虚假 |
| 已得到的愉悦、满足或失落 | 感受针对什么，牌义限制是什么，是否确有现实结果可比较 | 受用、评价、情境回应；满足不自动取消检验，失望不自动证明从未产出 |
| 关系与环境的水 | 谁在回应谁，情境提供或限制了什么，影响范围能否确定 | 维系、滋养、受制、共有条件；不直接归为当事人的内在机制 |

这些是观察分支，不是新增水牌词典；只有所用牌义容许的分支才进入本盘。灵视题中的感受、愿景、受用与失落，先检查是否在说明内部体验及其组织形态，不直接默认它们是对现实项目成败的评价。
K2 可独立讨论丰富的体验性内容、情绪色彩、受用或尚需整理的形态；同一组水牌保持并列。具体意象模态有支持时可进一步说明，未锁定模态则保留在体验性内容层。体验内容有多面，不自动成为准确辨识这些内容的能力。
K3 主动检查水提供什么材料和工作要求、土有何加工或固定动作；两端可在本题相接时，形成“体验进入加工、成为可用材料”的功能候选，不要求先有用户成品记录。实际已经交付、准确或可长期重复另判；水→土仍不是必经路线。
能理解、能表达、能保存、能交付分别判断；功能候选成立时保留该项，不因其他项未知全部撤回。

## 土：辨明生成、实践与限制

保留土卡的并列两层：人的资源、条件、实践与刻意练习；自然的生成场所、消长循环与客观限制。
冷干、晦暗、致密、静止与重用于说明持形、稳定、实质和边界；土的内含层次仍可带水、风与火。
“静止”不抹去具体牌义中的劳动、制作或反复；循环稳定也不能不经牌义就扩成持续做事的能力。

| 本盘可能辨认的作用 | 分析方向 | 结论范围 |
|---|---|---|
| 材料与条件 | 已有、可调用、正在生成、受限制分别是什么 | 资源状态不直接等于会使用资源 |
| 实际制作与成形 | 有何加工动作、完成到哪一层、成品能做什么 | 一段文字、解释稿或语言作品也可作为土的成品，条件是牌义支持实际制成或留存 |
| 程式与反复实践 | 重复的是动作、材料处理、练习还是维护；每轮是否有产出 | 能持续做某件事，不自动等于能修正其方向 |
| 细节精修 | 是否将力量集中于细部、精度与规格，达到何种限度 | 此种方式少，不排除粗细有度的制作或可重复流程 |
| 结果复核与调整 | 是否有结果比较、反馈接入，以及依反馈修改的动作 | 有记录不等于已复核，有复核不等于已调整 |
| 生成与限制 | 材料自身如何生长、耗损、恢复；哪些条件由环境决定 | 不把环境的限制自动写成人的懒惰、迟钝或能力不足 |

“能反复”“精细程度高”“有反馈与改判”是三个不同判断，需要分别落证。土牌在基线时保留其正常可用的加工形态，不因它未突出便要求用户先证明加工存在；显著长处与基本可用分开。
产出以语言为载体时，表达过程可有风的功能，实际形成并可使用的成果可有土的功能；仍以具体牌义分别支持。
土中一个具体形态较少，只限制该形态主导的候选；先查本盘是否有同功能的其他实现，再判断功能受限。

## 宫廷牌：方式与花色共同保留

按原性质卡“阶级元素与花色元素合定”读取，写明花色提供的领域与阶级元素提供的方式。
例如 Air of Earth 可检查风式调度如何体现于土的实务；不能用外层 hot+moist 覆盖掉内层 Earth。
两张土牌的方法或节奏有差异，先分别辨质；仅凭外层性质相反，不足以判它们实际无法配合。
用于本专题同元素关系检查时，宫廷牌保留内层花色归属。
因此不能将 Air of Earth 改算独立风端，再与另一张土牌建立伪跨元素因果来绕过同元素规则。
属性上的复合关系解释本牌形态，不凭空增添第二个事件节点。

## 单元素产物：并列形态谱

每个元素先交付并列谱：哪些形态被强调，哪些较少被强调，哪些在基线正常在场。
次数、偏多偏少、正逆和花色数字序列都不提供人物事件的时间顺序。
同元素内不写“先甲后乙”“甲导致乙”的时间或因果链；多张水牌也不组成满足、停工、失望的剧情。
单牌原义自带的动作与限制照录，但不借它替其他同元素牌安排前后。
火与审判等归属同一元素时也照此处理，不能因一张来自大阿卡纳位就假装跨元素。
跨元素才有资格提出因果候选，且须通过主流程的关系证据检查；具备资格不代表关系成立。
同场共存、功能相似、互补、张力与实际因果分开记录，没有因果材料时保留前三种分析价值。
当事人补充的实际先后另标来源，用于核对功能候选，不倒写为频数或同元素组合已推出的顺序。

## 交给画像层的产出

输出一张紧凑的功能表；每行保留一项可辨认的判断，不为凑齐能力模块制造缺口。

| 元素／牌义动作与来源 | 对象与性质 | 本题功能及实现方式 | 支持条件／限制 | 本盘证据范围 |
|---|---|---|---|---|
| 具体动作；所用正文版本 | 人或环境，已锁定或并列分支；轴如何说明动作 | 对什么材料做什么，形成什么；与其他方式的区别 | 有效处、成立条件、受限处各据材料填写 | 直接牌义、关系支持或用户补充；偏少只限制何种形态 |

随后分别写单元素并列谱，以及待主流程审核的跨元素关系候选；不在并列谱中夹带顺序。
涉及同一功能的正反材料必须合议：若一处支持反复推进，另一处要判不能持续，须说明对象、方式或条件的差异。
差异未锁定时保留竞争候选，不把较负面的候选自动扩成全人的长期特征。
没有被强调与有明确受限材料分别呈现；同功能存在可用通路时，把限制收回到具体方式。
本页完成标志是牌义、性质、功能及其范围能逐项对应，画像层能据此写人事判断，而非从元素名猜人物性格。
