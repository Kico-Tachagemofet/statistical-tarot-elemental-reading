# 从材料到论断：允许怎样连接

本页把材料、功能和关系接成可复核的论断。统计是无序分布；图里的箭头若出现，只能来自明确允许且有依据的作用，不来自排版。

## 1. 先分清五件事

| 层 | 回答什么 | 不从这一层自动得到什么 |
|---|---|---|
| 频数／偏离 | 本盘强调了哪张牌的哪种形态 | 先后、持久时间、个人能力有无 |
| 完整牌义 | 什么内容或动作，附什么条件 | 已锁定的现实对象、确定发生的事件 |
| 属性与元素 | 该动作怎样运行、处在什么层 | 脱离内容的功能标签、固定人体工序 |
| 本题功能 | 这次处理什么、产出什么、依什么条件 | 别的输入形式或别的任务也同样擅长 |
| 关系 | 具体两端怎样作用或共同限制解释 | 连续多段时间线、额外习惯与人格原因 |

把“满意”翻成“认为作品已完成”，就换了处理对象；把“能重组文本”翻成“任何体验都立即可言说”，就扩大了输入形式。后一步每增加一个主张，都要找到前层的具体支持。

## 2. 元素身份固定后才谈关系

- 数字牌主元素取花色；宫廷主元素仍取花色，阶级／外层元素说明其方式。`Air of Earth` 是风式运行的土，不能为建立跨元素因果把它改算风。
- 大牌按本次资料的明确元素标签并入；标签来源记录 Book T 或作者包。大牌位不是第五个可以和任意牌形成因果的元素。
- 未指定元素的大牌可提供语义限定或增强，不能仅凭行星、冷热干湿、某句“推动”或故事需要临时赋元素。它不进入本版元素因果；其自身内容仍可进入功能判断。
- 语义主导和统计主元素分开。混合元素说明内部结构，不把一张牌拆成两个独立证据节点对自己造因果。

## 3. 同元素是无序形态集合

本专题的关系规则是：**偏多的牌没有时间顺序；同种元素不可以出现先 xx 后 xx 的因果关系，只有不同元素之间才有因果关系。** 本专题把它实现为：同元素不生成时序边或因果边；跨元素通过具体机制核对后才可保留因果候选。

同元素允许做三件事：

1. **并列辨认**：同一元素中有几种不同内容，分别被强调到什么程度。
2. **区分适用范围**：哪种形态适合解释当前对象，哪种较少强调而限制“由它主导”的读法。
3. **辨认张力**：几种要求、状态或不同结果形态是否同时构成解释压力。张力本身不提供谁引发谁。

不得将“表达鲜明、说理受限、思路破裂”三种风形态写成“先说很多，因而被限制，最后崩断”。牌号从小到大、次数从多到少、同元素分布形状都不改变这条规则。

“两端强、中段薄”“火花—经营—落槌”若被用来诊断某人的发展或持续能力，也是给同元素安排序列，不能用空间比喻绕过本条。各形态的内容和主导程度分别判断。

一张牌的原义可包含阶段、条件或动作过程；保留其原义，不把它扩成这盘其他同元素牌之间的时间线。用户明确描述的实际时间单列为用户经验；这类描述不能挂上牌面因果关系编号。

## 4. 跨元素关系的判定顺序

先问两端是否处理同一对象，或是否有明确的传递关系。仅仅都出现“完成”“力量”“智慧”，或有同一行星、源质、路径，不够。

作用对象由原问、完整牌义与两端具体动作共同确定，写明什么材料或作用由一端传到另一端。例如整理劳动与情绪体验并存时，先分别保留实务能力和情绪状态；将劳动判成体验加工，需要具体说明两端为什么处理同一内容。判断可以来自有依据的符号关系，用户经验另列来源。关系成立后，按 [能力依据与优先级](capability-evidence.md) 判断它支持哪项能力；普通响应、理解或制作保留各自的功能身份。

再选择实际有根据的关系：

| 关系 | 成立需要什么 | 应产生什么判断 |
|---|---|---|
| 背景／条件 | 一端具体限定另一端的范围、资源、环境或边界 | 在什么条件下发挥；不自动写成前因后果 |
| 两极 | 两端各自形成焦点，性质或要求有对立／差别；尚未证实互动 | 两种处境并存及张力；不推彼此排斥的现实结局 |
| 共创 | 具体的两端参与组织、形成一项新形态／成果，有材料说明怎样共同参与 | 新形态由什么共同构成；时间另看 |
| 因果候选 | 两端主元素不同；作用对象可相接；有明确动作说明一端怎样改变另一端；牌义与适用关系方法均支持 | 哪种作用引起哪种回应／变化，明确范围；不自动加“随后”“终于” |
| 未定连接 | 缺对象对应、缺作用机制或缺端点材料 | 保留已有功能，指出哪一环尚未建立 |

**不同元素是因果候选的必要条件，不是充分条件。** 先有具体动作，再用火水交感、水土影响、火气纯化等方法解释；风的连接只表明可以传递，不等于因果已经发生。

对每条保留的跨元素关系，AUDIT 用一行或短段写清：

> R编号：类型；甲端的具体动作及主元素；乙端的具体内容及主元素；作用对象；甲怎样改变／限定／配合乙；两端短引及连接依据；是否具有独立时间资料。

没有机制证据时，就把“导致”改回关系实际支持的种类，不以含糊的“可能导致”保留无依据箭头。已有具体作用与双方材料时，保留有支持的功能判断，不要求先获得现实履历证明每一种符号关系。用户要求的“你可能／你或许”是灵视成稿的措辞，不降低后台核对具体作用的要求，也不要求把有支持的功能退成未覆盖。

## 5. 关系方向、时间、链条分开

- “甲推动乙”描述作用方向；它们可以共同运作，不能额外推成先完成甲、之后才出现乙。
- 有独立时间资料时标明来源。统计表和牌号不属于时间资料；领域规定先准备再制作，是任务程序，也不是个人已发生事实。
- `火A → 水B` 与 `水C ⇢ 土D` 可以分别成立。B、C 是否同一内容必须核对；即使一致，也不能仅因共用水将它们自动串成一条事件时间线。
- 用户提供实际流程后，可以记录其中各步及回路，再与符号功能核对；仍保留用户来源，不把真实流程冒充由本盘无序抽样推得。

## 6. 从功能谱收束能力

能力判断的最小单位是“**处理某类内容、在某项任务中、以某种方式完成某个动作**”。例如“能把零散概念整理成便于查用的说明”，比“转译强”更可检验，也不偷偷包括身体感或图像的解码。

一个功能可以由不同元素方式支持；相同元素也可以处理不同对象。先收集本盘支持这个功能的不同实现，处理互相限制的材料，再给结论。

区分内容状态、加工动作与加工能力：有受用和失落不直接等于辨识精确，呈现计划断裂不直接等于擅长找出断点。能力依据由完整牌义及全场关系形成，按 [能力依据与优先级](capability-evidence.md) 收束；题型分类承接已形成判断，细化方式。精准、熟练或高稳定度各需相应的具体支持。

把支持状态与强调程度分开：

- **支持**：材料支持哪种具体做法及范围；在后台明确记录，灵视成稿用“你可能／你或许”承载相同范围。
- **相反材料**：说明它具体反对哪种做法主导，或支持何种困难；不能顺手否定邻近功能。
- **未覆盖**：这次没有取得足以判断某一具体层面的材料；注明是功能、模态、稳定度、准确性还是来源，不参加弱项评分，不触发领域门槛排除。没有经验自述不等于没有符号层功能支持。

例如牌义与全场关系已支持某类感知或接收时，可以保留功能判断，同时将视觉模态、稳定度分别记为未定；只有情绪回应的材料则按情绪回应描述。功能可用与它是否为本盘长处分开比较。

普通／极端偏少限制相应牌形的主导性，不等于某种现实能力不存在。正向形态支持反复制作，另一形态的低强调不能不经解释就把它整个抹去。频数不能替代作用对象和功能范围。

## 7. 画像到散文的传递

冻结 A 判断时保留：处理对象、功能、实现方式、支持与反证、邻接未知项。领域分析只将这个范围放进具体任务；不能借领域要求把未知功能补成弱项。

成稿可改语气和句法，不可改变判断对象、范围或因果结构。若 A 只支持“反复试做、细部精修未突出”，REPORT 就不能写“没有后劲、很快放弃”；若 A 支持“组织概念表达”，不能写“接到的画面随口就能说清”。

写完用换对象检查：把文本换成非语言体验，把当前成品换成长期服务，把细节精修换成反馈改判，原结论是否还获得同样证据？不能获得时保留边界。这个检查帮助确定结论能到哪里，不要求把所有有依据的句子降成含糊表达。

灵视正文的语气统一：每句面向人的接收、体验、领会、转译、加工及强弱判断，以“你可能……”或“你或许……”表述；定义、原文和统计事实除外。加限定词不能挽救对象或范围已改变的句子。
