# 合成换牌样例

以下六个情境是行为验收材料，不是真实个人占卜。共同背景固定：讨论玄学学习与实践中的突出功能，四元素总量持平，其余形态在基线；每个情境只有指定牌被强调。没有随机抽取、实际频数或个人经历。

完整依据见 [牌义与占星校准](../references/card-astrology.md)。两张大牌的作者分支以实际启用 Kico 大牌正文为前提。

| 情境 | card_id | 保持背景不变时的具体判断 |
|---|---|---|
| C01 | `9_wands` | 抗扰与恢复投入突出。受挫后仍能接回原先认领的工作；坚持也可能固执。放入内修日课，重点是打断之后的重返，以及能否根据观察调整用力。 |
| C02 | `10_wands` | 持续施压突出，工作靠要求维持推进。力量越重，代价与对抗越应进入解释。放入同一日课，重点转成是否把漂移当作必须压服的对抗；不沿留九的恢复能力。 |
| C03 | `3_disks` | 构作已开始，零散投入正在形成可用形体，整体仍待建立。放入学习工具制作，能够开始搭出练习样张；制作动作与后续释义质量分别看。 |
| C04 | `7_disks` | 劳动与可延续成果脱节，投入可以很多而所得不结实。放入相同学习工作，要看做过的练习留下了什么、偶尔所得能否进入下一次任务；不把等待自动解释成丰收。 |
| C05 | `atu_02_high_priestess` | 依作者正文，内部研究、知识储备和关系梳理突出，有限展示不等于解释无能。放入文本释义，可比较候选解释的依据；细节过密时收束可能变慢。 |
| C06 | `atu_18_moon` | 依作者正文，材料引起的心境参与理解、面对和选择。放入自省工作，重点是分清材料与由此形成的反应；不能沿留女祭司的知识储备与系统解释长处。 |

## 实际验收到的差别

- 权杖九换十：从抗扰、恢复、续行，转为压力、对抗与施力代价。同属月亮射手／土星射手所在的火象背景，不统一写“意志强”。
- 星币三换七：从建设已经启动，转为劳动与成果脱节。同属土牌，不统一写“擅长落地”。
- 女祭司换月亮：从内部知识处理，转为心境介入判断。不能因为都有内部／水的色彩，就统一写“接收强”。

验收看判断内容和任务后果是否改变，不要求输出固定词句。若替换关键牌后只改牌名而正文不动，应回到完整牌义重新解释。
