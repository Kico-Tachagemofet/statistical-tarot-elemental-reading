# 阶段 1 分读 brief（给五个位置子 agent）

> v3，2026-10-17。子 agent 只解牌意。元素性质判断、落轴、运作与维持、位置层排除全部收回主 agent 的阶段 2。

主 agent 派五个子 agent 并行，每个只读一个位置。把本文件全文、该位置的数据卡 `positions/<key>.md`、`references/properties.md`（只用"花色序列与宫廷牌"一节）一起交给子 agent；大阿卡那位另给 `references/relations.md` 做元素标参照。子 agent 只能看自己那一堆的数据，不得读别的位置，不得读元素方法卡。

## 你要交付的东西

你负责五位置牌阵里的一个位置。你的产物是这一堆突出牌的**牌意**：每张牌说了什么动作、什么品质、什么限制，这张牌在本花色的序列里落在哪一段，它可能落在人的层还是环境层，偏多或偏少说明本堆内部哪几种形态被强调、哪几种较少被强调。你不判断这股元素是什么样的元素，不落冷热干湿的轴，不写它靠什么维持，不写全盘结论。那些由主 agent 在看见五堆之后做。

## 纪律

1. **牌义先行，属性加色。** Book T 牌义摘要与自定牌意正文（若提供）是牌义；源质与四世界、旬星与尊贵、生命之树路径是属性。属性解释这种形态在哪一层运作、方向有没有锐化、有没有外部调节，不能冒充牌义。星币三的源质写着 "realization of action"，牌义只到"营造与动工，是日后才确立之事的开端"，不许写成"事情已实现"。
2. **牌义保留全幅。** 一张牌有几面就写几面，不挑一面服务故事。宝剑二有恢复的和平、有从痛苦里生出的力量、有真假掺杂，三面都进。
3. **牌义动作原样保留。** 对抗、压迫、守线、和气、迂回、承受这些词是牌义给的形态，照原样写，不翻成"静止""承载"这类轴的词。轴由主 agent 落。
4. **花色序列。** 数字牌一到十是该元素从源头到落底的积累，高位是最密最重的形态，宫廷牌是元素的人格化。写明这张牌落在序列的哪一段（首牌到三是发端，四到六是中段，七到十是高位），高位具体是什么形态由 Book T 牌义定。
5. **在基线不等于不在场。** 接近基线的牌是"在场但未被强调"，必须这样写，不许写成"缺""没有""缺席"。只有偏少才能说"较少被强调"；极端偏少才能说"这一形态明确不在场"。本位置的中段或主体牌全在基线时，要明确写一句"这些形态正常在场"。
6. **逆位比例只作探针。** 不设门槛，只给方向：这个动作是否可逆、位置是否颠倒、同一状态是否走向坏结果。不许把逆位比例换算成"有多少比例是坏的一面"之类的评价。
7. **偏多定"是哪一种"，偏少定"较少被强调的是哪一种"。** 普通偏离不单独生成候选，但用来定形态；引用时标"普通偏离"。
8. **技能、判断、胜利这类牌义不翻成"当事人正在行动"。** 它们可以是状态、姿态、对别人的提醒、别人对当事人的态度。给视角候选，不定夺。
9. **两层只给候选。** 这张牌可能落在人的层（我的动力、我的情绪、我的思路、我的资源）还是环境层（客观趋势、共有情境、媒介通道、自然条件），按牌义写哪一层可能、为什么，不定夺。
10. **对象不填。** 牌没锁定的人、事、地点、媒介，一律写"未锁定"，不用背景去补。
11. **只许引用本堆的牌。** 报告末尾的"牌面依据"只能出现本位置的牌名。

## 输出格式（小标题固定，阶段 2 要靠它合并）

```
# <位置名> 牌意报告

## 1. 位置概况（量）
本堆被抽到多少次、预期多少、z。只说数字，不判断偏多偏少（那由主 agent 按五堆相对读）。

## 2. 突出牌逐张解牌
每张一段，顺序固定：牌义全幅 → 属性加色 → 本花色序列位置 → 两层候选 → 偏多／偏少说明本堆内部什么形态被强调或较少被强调 → 正逆探针。偏少的牌也写。
无突出牌则写"无突出"，并说明本堆各形态都在基线，意味着它们在场里正常运作、没有被特别强调或压低。

## 3. 本堆内部形态分列
三行：偏多的形态（每张一条，用牌义动作命名）；偏少的形态（同上，标"较少被强调"或"明确不在场"）；在基线的形态（点名，写"在场但未被强调"）。

## 4. 对应原问的指向（候选）
两到四条候选，每条写清：这是谁的（问的人、被问的人、环境），是状态、姿态还是提醒，指向什么。只从牌义出发，不定夺，不排序。

## 5. 开放项
本位置看不清、需要别的位置或原问语境才能定的事。

牌面依据: 本堆突出牌的次数、正逆、z、Book T 摘要子串、属性代号；普通偏离标"普通偏离"。
```

## 大阿卡那位的附加任务

大阿卡那位的子 agent 另加一节，放在第 5 节之后：

```
## 6. 元素标
每张突出大牌一行：牌名 → 元素标（来源：Book T 归属 / 自定牌意 vX / 未指定）→ 一句话说明这张牌给该元素线带去的是哪一种形态（用牌义动作说，不落轴）。
未指定的写明"留给主 agent 做元素结论增强"。
```

数据卡里已经按规则给了元素标。你照数据卡的标写，不自行改标；若你认为某张牌按牌义该归别的元素，写进第 5 节开放项，由主 agent 处理。

## 不要做的事

- 不写元素性质判断，不落冷热干湿、三性质、轻重的轴，不写"这股火热而动"这类句子。
- 不写运作与维持，不写"它需要谁承载"。
- 不做位置层 Via Negativa。
- 不写全盘结论，不写 answer。
- 不读也不猜别的位置有什么。
- 不把接近基线写成缺席。
- 不把逆位比例写成评价。
- 不用"需要注意""有一定的""可能会有一些"这类空话。
- 不加价值评判（好坏、吉凶、惨不惨）。
